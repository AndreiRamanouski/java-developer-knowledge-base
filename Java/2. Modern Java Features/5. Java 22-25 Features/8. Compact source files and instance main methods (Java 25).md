# Compact Source Files and Instance Main Methods (Java 25)

> **Applies to:** Java 25+ · **Last updated:** 2026-11-21

## Overview

> **Status:** Final in Java 25 ([JEP 512](https://openjdk.org/jeps/512)). Earlier previews: Java 21 ([JEP 445](https://openjdk.org/jeps/445), "Unnamed Classes and Instance Main Methods"), Java 22 ([JEP 463](https://openjdk.org/jeps/463), "Implicitly Declared Classes…"), Java 23 ([JEP 477](https://openjdk.org/jeps/477)) and Java 24 ([JEP 495](https://openjdk.org/jeps/495)). The final version renamed "implicitly declared classes" to **compact source files** and moved the `IO` helper class into `java.lang`.

Java 25 lets you write a program without the ceremony of `public class`, `static` and `String[] args`:

```java
void main() {
    IO.println("Hello, World!");
}
```

```bash
java Hello.java          # source-code launcher: compiles in memory and runs
```

Two independent features make this work:

1. **Instance main methods** — `main` may be an instance method, and may omit the `String[]` parameter.
2. **Compact source files** — a source file may declare fields and methods at the top level. The compiler wraps them in an implicitly declared, unnamed `final` class.

They're aimed at learning, scripts and small tools. Nothing changes for existing code.

---

## 1. Instance Main Methods

Any class can now be launched through one of these `main` signatures:

```java
public static void main(String[] args)   // classic
static void main(String[] args)          // non-public is OK
static void main()                       // no args
void main(String[] args)                 // instance method
void main()                              // instance method, no args
```

**Launch protocol:**

1. If the class has a `main(String[])` method (static or instance, any non-private access), that one is used; otherwise a `main()` with no parameters is used.
2. If the chosen method is an instance method, the launcher creates the object with the class's non-private no-arg constructor and then calls `main` on it.

```java
public class Greeter {
    private final String greeting = "Hi";

    void main(String[] args) {                  // instance main: can use fields
        String name = args.length > 0 ? args[0] : "there";
        System.out.println(greeting + ", " + name);
    }
}
```

## 2. Compact Source Files

If a source file has methods or fields outside any class declaration, it's a compact source file:

```java
// Todo.java
List<String> items = new ArrayList<>();       // instance field of the implicit class

void main() {
    String line;
    while ((line = IO.readln("todo> ")) != null && !line.isBlank()) {
        items.add(line);
        IO.println(items.size() + " item(s): " + items);
    }
}
```

Rules:

- The implicit class is `final`, lives in the unnamed package, extends `Object`, and has only a default constructor.
- It has **no name you can reference** from code, so other classes can't use it — it's an entry point only.
- It **must have a `main` method**.
- It can contain nested types (records, enums, interfaces, classes) alongside the methods:

```java
record Point(int x, int y) {}

void main() {
    var p = new Point(3, 4);
    IO.println(Math.hypot(p.x(), p.y()));
}
```

- It **automatically imports module `java.base`** (see [Module import declarations](5.%20Module%20import%20declarations%20(Java%2025).md)), so `List`, `ArrayList`, `Map`, `Path`, `Files`, `LocalDate` and the rest are available without imports. You can still add explicit imports.

## 3. The `java.lang.IO` Class

`IO` provides basic console I/O for beginners and scripts. It's in `java.lang`, so every class can use it without an import.

| Method | Behaviour |
|---|---|
| `IO.println(Object)` / `IO.println()` | Print with a newline to `System.out` |
| `IO.print(Object)` | Print without a newline |
| `IO.readln(String prompt)` | Print the prompt, read one line (returns `null` at end of input) |
| `IO.readln()` | Read one line |

`IO` is a convenience — `System.out` and `BufferedReader` still work exactly as before.

## 4. Running Source Files

```bash
java Todo.java                 # single file
java Main.java                 # multi-file programs: other .java files in the same
                               # directory tree are compiled on demand (Java 22+, JEP 458)
java --class-path 'lib/*' Main.java   # with dependencies
```

Shebang scripts work on Unix-like systems:

```java
#!/usr/bin/env -S java --source 25
void main() {
    IO.println("Disk usage report for " + System.getProperty("user.dir"));
}
```

```bash
chmod +x report && ./report    # the file must NOT end in .java when using a shebang
```

## 5. Growing Up: From Compact File to Regular Class

When a script grows, convert it by wrapping the members in a class declaration and adding the imports the file relied on:

```java
// Before (compact source file)
List<String> items = new ArrayList<>();
void main() { /* ... */ }
```

```java
// After (ordinary class)
import java.util.*;

public class Todo {
    private final List<String> items = new ArrayList<>();
    void main() { /* ... */ }
}
```

The body of the code doesn't change, so the learning path is smooth: start with methods, add classes when you need them.

---

## Summary

- `void main()` is a valid entry point; the launcher instantiates the class if `main` isn't static.
- Top-level methods and fields create an unnamed, final, implicitly declared class.
- Compact source files import `java.base` automatically.
- `java.lang.IO` offers `println`, `print` and `readln`.
- Run with `java File.java` — no separate compile step.
