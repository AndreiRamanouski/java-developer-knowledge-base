# Testing Database Migrations

## Overview

Testing database migrations is critical for preventing production failures. Comprehensive testing includes integration tests, rollback validation, checksum verification, multi-database compatibility, CI/CD automation, and performance benchmarking.

**Key Concept**: Database migrations are code that modifies critical infrastructure. Like all code, migrations must be thoroughly tested before production deployment to prevent data loss, downtime, and performance degradation.

### Basic Migration Test

**Simple Migration Test:**

```java
@SpringBootTest
@Testcontainers
@ActiveProfiles("test")
class LiquibaseMigrationTest {
    
    @Container
    static OracleContainer oracleContainer = new OracleContainer("gvenzl/oracle-xe:21-slim")
        .withDatabaseName("testdb")
        .withUsername("testuser")
        .withPassword("testpass")
        .withReuse(true);  // Reuse container across tests
    
    @DynamicPropertySource
    static void registerOracleProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", oracleContainer::getJdbcUrl);
        registry.add("spring.datasource.username", oracleContainer::getUsername);
        registry.add("spring.datasource.password", oracleContainer::getPassword);
        registry.add("spring.liquibase.enabled", () -> true);
    }
    
    @Autowired
    private DataSource dataSource;
    
    @Autowired
    private JdbcTemplate jdbcTemplate;
    
    @Test
    void shouldApplyAllMigrations() throws Exception {
        // Given - Container is started and Liquibase has run
        
        // When - Check that migrations were applied
        List<String> tables = getTableNames();
        
        // Then - Verify expected tables exist
        assertThat(tables).contains(
            "USERS",
            "ORDERS",
            "PRODUCTS",
            "DATABASECHANGELOG",
            "DATABASECHANGELOGLOCK"
        );
    }
    
    @Test
    void shouldCreateUsersTableWithCorrectSchema() {
        // When
        Map<String, String> columns = getTableColumns("USERS");
        
        // Then
        assertThat(columns)
            .containsEntry("USER_ID", "NUMBER")
            .containsEntry("USERNAME", "VARCHAR2")
            .containsEntry("EMAIL", "VARCHAR2")
            .containsEntry("CREATED_AT", "TIMESTAMP");
    }
    
    @Test
    void shouldCreateIndexesOnUsersTable() {
        // When
        List<String> indexes = getTableIndexes("USERS");
        
        // Then
        assertThat(indexes).contains(
            "IDX_USERS_EMAIL",
            "IDX_USERS_USERNAME"
        );
    }
    
    @Test
    void shouldEnforceForeignKeyConstraints() {
        // Given
        jdbcTemplate.update(
            "INSERT INTO users (user_id, username, email) VALUES (1, 'testuser', 'test@example.com')"
        );
        
        // When - Insert order with valid user_id
        jdbcTemplate.update(
            "INSERT INTO orders (order_id, user_id, total_amount) VALUES (1, 1, 100.00)"
        );
        
        // Then - Should succeed
        Integer count = jdbcTemplate.queryForObject(
            "SELECT COUNT(*) FROM orders", Integer.class
        );
        assertThat(count).isEqualTo(1);
        
        // When - Try to insert order with invalid user_id
        // Then - Should fail with constraint violation
        assertThatThrownBy(() -> 
            jdbcTemplate.update(
                "INSERT INTO orders (order_id, user_id, total_amount) VALUES (2, 999, 200.00)"
            )
        ).isInstanceOf(DataIntegrityViolationException.class);
    }
    
    private List<String> getTableNames() {
        return jdbcTemplate.queryForList(
            "SELECT table_name FROM user_tables ORDER BY table_name",
            String.class
        );
    }
    
    private Map<String, String> getTableColumns(String tableName) {
        String sql = """
            SELECT column_name, data_type
            FROM user_tab_columns
            WHERE table_name = ?
            """;
        
        return jdbcTemplate.query(sql, rs -> {
            Map<String, String> columns = new HashMap<>();
            while (rs.next()) {
                columns.put(
                    rs.getString("column_name"),
                    rs.getString("data_type")
                );
            }
            return columns;
        }, tableName.toUpperCase());
    }
    
    private List<String> getTableIndexes(String tableName) {
        return jdbcTemplate.queryForList(
            "SELECT index_name FROM user_indexes WHERE table_name = ? AND index_name NOT LIKE 'SYS_%'",
            String.class,
            tableName.toUpperCase()
        );
    }
}
```

```java
@SpringBootTest
@Testcontainers
class ChangeSetTest {
    
    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15-alpine")

    }

    private DataSource dataSource;
    
    private Liquibase liquibase;
    
    @BeforeEach
    void setUp() throws Exception {
        Connection connection = dataSource.getConnection();
        Database database = DatabaseFactory.getInstance()
            .findCorrectDatabaseImplementation(new JdbcConnection(connection));
        
        liquibase = new Liquibase(
            "db/changelog/db.changelog-master.yaml",
            new ClassLoaderResourceAccessor(),
            database
        );
    }
    
    @Test
    void testUserTableCreation() throws Exception {
        // When - Run only changesets up to user table creation
        liquibase.update(1, new Contexts("test"));
        
        // Then - Verify user table exists
        DatabaseMetaData metaData = dataSource.getConnection().getMetaData();
        ResultSet tables = metaData.getTables(null, null, "users", null);
        assertThat(tables.next()).isTrue();
        tables.close();
    }
    
    @Test
    void testDataMigration() throws Exception {
        // Given - Apply changesets up to before data migration
        liquibase.update(5, new Contexts("test"));
        
        // Insert test data in old format
        JdbcTemplate jdbcTemplate = new JdbcTemplate(dataSource);
        jdbcTemplate.update(
            "INSERT INTO users (user_id, first_name, last_name) VALUES (1, 'John', 'Doe')"
        );
        
        // When - Run data migration changeset
        liquibase.update(6, new Contexts("test"));
        
        // Then - Verify data was migrated correctly
        String fullName = jdbcTemplate.queryForObject(
            "SELECT full_name FROM users WHERE user_id = 1",
            String.class
        );
        assertThat(fullName).isEqualTo("John Doe");
    }
}
```

```java
@SpringBootTest
@Testcontainers
@TestMethodOrder(MethodOrderer.OrderAnnotation.class)
class RollbackTest {
    
    @Container
    static OracleContainer oracle = new OracleContainer("gvenzl/oracle-xe:21-slim");
    
    @DynamicPropertySource
    static void registerProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", oracle::getJdbcUrl);
        registry.add("spring.datasource.username", oracle::getUsername);
        registry.add("spring.datasource.password", oracle::getPassword);
        registry.add("spring.liquibase.enabled", () -> false);
    }
    
    @Autowired
    private DataSource dataSource;
    
    private Liquibase liquibase;
    private Database database;
    
    @BeforeEach
    void setUp() throws Exception {
        Connection connection = dataSource.getConnection();
        database = DatabaseFactory.getInstance()
            .findCorrectDatabaseImplementation(new JdbcConnection(connection));
        
        liquibase = new Liquibase(
            "db/changelog/db.changelog-master.yaml",
            new ClassLoaderResourceAccessor(),
            database
        );
    }
    
    @Test
    @Order(1)
    void shouldApplyMigrations() throws Exception {
        // When
        liquibase.update(new Contexts("test"));
        
        // Then
        assertThat(tableExists("USERS")).isTrue();
        assertThat(tableExists("ORDERS")).isTrue();
    }
    
    @Test
    @Order(2)
    void shouldRollbackLastChangeSet() throws Exception {
        // Given - Apply all migrations
        liquibase.update(new Contexts("test"));
        
        String lastTable = "ORDERS";
        assertThat(tableExists(lastTable)).isTrue();
        
        // When - Rollback last changeset
        liquibase.rollback(1, new Contexts("test"));
        
        // Then
        assertThat(tableExists(lastTable)).isFalse();
        assertThat(tableExists("USERS")).isTrue(); // Earlier table still exists
    }
    
    @Test
    @Order(3)
    void shouldRollbackToTag() throws Exception {
        // Given - Apply all migrations
        liquibase.update(new Contexts("test"));
        
        // When - Rollback to v1.0 tag
        liquibase.rollback("v1.0", new Contexts("test"));
        
        // Then - Verify state at v1.0
        assertThat(tableExists("USERS")).isTrue();
        assertThat(tableExists("ORDERS")).isFalse(); // Added after v1.0
    }
    
    @Test
    @Order(4)
    void shouldRollbackToDate() throws Exception {
        // Given - Apply all migrations
        liquibase.update(new Contexts("test"));
        
        // When - Rollback to specific date
        Date rollbackDate = Date.from(
            LocalDate.of(2024, 1, 1)
                .atStartOfDay(ZoneId.systemDefault())
                .toInstant()
        );
        
        liquibase.rollback(rollbackDate, new Contexts("test"));
        
        // Then - Verify only changesets before date exist
        assertThat(tableExists("USERS")).isTrue();
        // Other assertions based on your changelog dates
    }
    
    @Test
    @Order(5)
    void shouldReapplyAfterRollback() throws Exception {
        // Given - Apply migrations
        liquibase.update(new Contexts("test"));
        
        // When - Rollback
        liquibase.rollback(2, new Contexts("test"));
        
        // Then - Reapply should work
        assertThatCode(() -> liquibase.update(new Contexts("test")))
            .doesNotThrowAnyException();
        
        // Verify final state is correct
        assertThat(tableExists("USERS")).isTrue();
        assertThat(tableExists("ORDERS")).isTrue();
    }
    
    @Test
    @Order(6)
    void shouldHandleRollbackWithData() throws Exception {
        // Given - Apply migrations and insert data
        liquibase.update(new Contexts("test"));
        
        JdbcTemplate jdbcTemplate = new JdbcTemplate(dataSource);
        jdbcTemplate.update(
            "INSERT INTO users (user_id, username, email) VALUES (1, 'testuser', 'test@example.com')"
        );
        
        // When - Rollback table with data
        liquibase.rollback(5, new Contexts("test"));
        
        // Then - Table and data should be gone
        assertThat(tableExists("USERS")).isFalse();
        
        // When - Reapply
        liquibase.update(new Contexts("test"));
        
        // Then - Table exists but data is gone (as expected)
        assertThat(tableExists("USERS")).isTrue();
        Integer count = jdbcTemplate.queryForObject(
            "SELECT COUNT(*) FROM users", Integer.class
        );
        assertThat(count).isEqualTo(0);
    }
    
    private boolean tableExists(String tableName) throws Exception {
        DatabaseMetaData metaData = dataSource.getConnection().getMetaData();
        ResultSet tables = metaData.getTables(null, null, tableName.toUpperCase(), null);
        boolean exists = tables.next();
        tables.close();
        return exists;
    }
}
```

```java
@SpringBootTest
@Testcontainers
class ChecksumValidationTest {
    
    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15-alpine");

            databaseChangeLog:
              - changeSet:
                  id: checksum-test
                  author: test
                  changes:
                    - createTable:
                        tableName: test_table
                        columns:
                          - column:
                              name: id
                              type: BIGINT
            """;
        
        Path changelogPath = Files.createTempFile("changelog", ".yaml");
        Files.writeString(changelogPath, originalChangelog);
        
        Connection connection = dataSource.getConnection();
        Database database = DatabaseFactory.getInstance()

        Liquibase liquibase = new Liquibase(
            changelogPath.toString(),
            new FileSystemResourceAccessor(changelogPath.getParent().toFile()),
            database
        );
        
        liquibase.update(new Contexts());
        
        // When - Modify changeset
        String modifiedChangelog = """
            databaseChangeLog:
              - changeSet:
                  id: checksum-test
                  author: test
                  changes:
                    - createTable:
                        tableName: test_table
                        columns:
                          - column:
                              name: id
                              type: BIGINT
                          - column:
                              name: name
                              type: VARCHAR(100)

            new FileSystemResourceAccessor(changelogPath.getParent().toFile()),

        // When - Clear checksums
        liquibase.clearCheckSums();
        
        // Then - Should be able to run again without errors
        assertThatCode(() -> liquibase.update(new Contexts("test")))
            .doesNotThrowAnyException();
    }
    
    @Test
    void shouldValidateChecksums() throws Exception {
        // Given
        Connection connection = dataSource.getConnection();
        Database database = DatabaseFactory.getInstance()
            .findCorrectDatabaseImplementation(new JdbcConnection(connection));
        
        Liquibase liquibase = new Liquibase(
            "db/changelog/db.changelog-master.yaml",
            new ClassLoaderResourceAccessor(),
            database
        );
        
        // Apply migrations
        liquibase.update(new Contexts("test"));
        
        // When/Then - Validate should succeed
        assertThatCode(() -> liquibase.validate())
            .doesNotThrowAnyException();
    }
    
    @Test
    void shouldRetrieveStoredChecksums() throws Exception {
        // Given
        Connection connection = dataSource.getConnection();
        Database database = DatabaseFactory.getInstance()
            .findCorrectDatabaseImplementation(new JdbcConnection(connection));
        
        Liquibase liquibase = new Liquibase(
```

```java
@SpringBootTest
@Testcontainers
class ChecksumPreventionTest {
    
    @Container
    static OracleContainer oracle = new OracleContainer("gvenzl/oracle-xe:21-slim");
    
    @DynamicPropertySource
    static void registerProperties(DynamicPropertyRegistry registry) {

        registry.add("spring.liquibase.enabled", () -> false);

    @Autowired
    private DataSource dataSource;
    
    @Test
    void shouldUseRunOnChangeForViews() throws Exception {
        // Given - Changeset with runOnChange=true
        String changelog = """
            databaseChangeLog:
              - changeSet:
                  id: create-view
                  author: test
                  runOnChange: true
                  changes:
                    - createView:
                        viewName: user_summary
                        selectQuery: SELECT user_id, username FROM users
            """;
        
        Path changelogPath = Files.createTempFile("changelog", ".yaml");
        Files.writeString(changelogPath, changelog);
        
        Connection connection = dataSource.getConnection();
        Database database = DatabaseFactory.getInstance()
            .findCorrectDatabaseImplementation(new JdbcConnection(connection));
        
        // Create users table first
        JdbcTemplate jdbcTemplate = new JdbcTemplate(dataSource);

            changelogPath.toString(),
            new FileSystemResourceAccessor(changelogPath.getParent().toFile()),
            database
        );
```

```java
            .as("Tables on " + provider.getDatabaseType())
            .contains(normalizeTableName("users", provider.getDatabaseType()));

            new DatabaseProvider("Oracle", oracle),
            new DatabaseProvider("PostgreSQL", postgres),
            new DatabaseProvider("MySQL", mysql)
        );
    }
    
    private DataSource createDataSource(DatabaseProvider provider) {
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl(provider.getContainer().getJdbcUrl());
        config.setUsername(provider.getContainer().getUsername());
        config.setPassword(provider.getContainer().getPassword());
        return new HikariDataSource(config);
    }
    
    private List<String> getTables(JdbcTemplate jdbcTemplate, String dbType) {
        return switch (dbType) {
            case "Oracle" -> jdbcTemplate.queryForList(
                "SELECT table_name FROM user_tables", String.class
            );
            case "PostgreSQL" -> jdbcTemplate.queryForList(
                "SELECT tablename FROM pg_tables WHERE schemaname = 'public'", String.class
            );
            case "MySQL" -> jdbcTemplate.queryForList(
                "SELECT table_name FROM information_schema.tables WHERE table_schema = DATABASE()",
                String.class
            );
            default -> List.of();
        };
    }
    
    private String normalizeTableName(String tableName, String dbType) {
        return "Oracle".equals(dbType) ? tableName.toUpperCase() : tableName.toLowerCase();
    }
```

```java
class MigrationLoadTest {
    
    @Container
    static PostgreSQLContainer<?> postgres = new PostgreSQLContainer<>("postgres:15-alpine");
    
    @DynamicPropertySource
    static void registerProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.datasource.url", postgres::getJdbcUrl);

    @Autowired
    private DataSource dataSource;
    
    @Test
    void shouldHandleConcurrentMigrations() throws Exception {
        // Given
        int threadCount = 5;
        ExecutorService executor = Executors.newFixedThreadPool(threadCount);
        CountDownLatch latch = new CountDownLatch(threadCount);
        List<Future<MigrationResult>> futures = new ArrayList<>();
        
        // When - Multiple threads try to run migrations
        for (int i = 0; i < threadCount; i++) {
            final int threadId = i;
            Future<MigrationResult> future = executor.submit(() -> {
                try {
                    latch.countDown();
                    latch.await(); // All threads start together
                    
                    long start = System.currentTimeMillis();
                    
                    Connection connection = dataSource.getConnection();
                    Database database = DatabaseFactory.getInstance()
                        .findCorrectDatabaseImplementation(new JdbcConnection(connection));
                    
                    Liquibase liquibase = new Liquibase(
                        "db/changelog/db.changelog-master.yaml",
                        new ClassLoaderResourceAccessor(),
                        database
                    );
                    
                    liquibase.update(new Contexts("test"));
                    
                    long end = System.currentTimeMillis();
                    
                    connection.close();
                    
                    return new MigrationResult(threadId, true, end - start, null);
                    
                } catch (Exception e) {
                    return new MigrationResult(threadId, false, 0, e.getMessage());
                }
            });
            
            futures.add(future);
        }
        
        // Then - Collect results
        List<MigrationResult> results = new ArrayList<>();
        for (Future<MigrationResult> future : futures) {
            results.add(future.get());
        }
        
        executor.shutdown();
        
        // Verify - One succeeded, others got lock exceptions
        long successCount = results.stream().filter(MigrationResult::isSuccess).count();
        long failureCount = results.stream().filter(r -> !r.isSuccess()).count();
        
        System.out.println("\nConcurrent Migration Results:");
        System.out.println("Successes: " + successCount);
        System.out.println("Failures (expected due to locking): " + failureCount);
        
        results.forEach(r -> 
            System.out.printf("Thread %d: %s (%dms) - %s%n", 
                r.getThreadId(), 
                r.isSuccess() ? "SUCCESS" : "FAILED",
                r.getDuration(),
                r.getErrorMessage() != null ? r.getErrorMessage() : "")
        );
        
        // At least one should succeed
        assertThat(successCount).isGreaterThanOrEqualTo(1);
    }
}

@Data
@AllArgsConstructor
class MigrationResult {
    private int threadId;
    private boolean success;
    private long duration;
    private String errorMessage;
}
```

## Interview Questions

**Q1: Why use Testcontainers instead of H2 for testing?**

Testcontainers provides real database instances (Oracle, PostgreSQL, MySQL) that match production behavior. H2 has different SQL dialects, features, and constraints than production databases, leading to false confidence. Real databases catch issues with database-specific features, stored procedures, and subtle behavioral differences.

**Q2: How do you test rollback procedures?**

Create tests that: (1) apply migrations, (2) execute rollback, (3) verify database state matches pre-migration, (4) reapply migrations to test idempotency. Also generate rollback SQL for manual review and test rollback to specific tags/dates.

**Q3: What's the purpose of checksum validation?**

Checksums detect unauthorized modifications to executed changesets. If a changeset's content changes after execution, Liquibase detects the mismatch and prevents re-execution, protecting against accidental schema corruption or configuration drift.

**Q4: How do you test migrations against multiple databases in CI/CD?**

Use matrix builds in CI/CD (GitHub Actions, GitLab CI) to run tests against Oracle, PostgreSQL, and MySQL containers simultaneously. Use parameterized tests or separate test classes per database. Testcontainers makes this straightforward with Docker-based databases.

**Q5: What performance metrics should you measure for migrations?**

Measure: (1) total migration time, (2) per-changeset execution time, (3) data migration throughput (rows/second), (4) index creation time on large tables, (5) lock acquisition time in clustered environments. Set performance budgets and fail builds if exceeded.
