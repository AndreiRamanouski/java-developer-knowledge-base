# Flyway in Microservices Architecture

## Overview

Managing database migrations in microservices requires careful coordination, clear service boundaries, and strategies for handling distributed data. Flyway can be adapted to various microservices patterns while maintaining data consistency and service independence.

**Key Concept**: In microservices, each service should own its schema evolution. Flyway enables autonomous database management per service while providing patterns for coordination when services must interact.

## 1. Per-Service Database Migrations

### Database-Per-Service Pattern

Each microservice owns and manages its own database schema.

### Service-Specific Flyway Configuration

```java
@Configuration
public class UserServiceFlywayConfig {
    
    @Bean
    public Flyway userServiceFlyway(
            @Qualifier("userDataSource") DataSource dataSource,
            @Value("${spring.application.name}") String serviceName) {

            .dataSource(dataSource)

                "service.name", serviceName,
                "service.version", getServiceVersion()
            ))
            .load();
    }
    
    private String getServiceVersion() {
        // Get from manifest, build info, or environment
        return "1.0.0";
    }
}
```

### Avoiding Cross-Service Foreign Keys

**❌ Anti-Pattern:**

```sql
-- DON'T: Foreign key across services
CREATE TABLE orders (
    order_id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL,
    CONSTRAINT fk_orders_user FOREIGN KEY (user_id)
        REFERENCES user_schema.users(user_id)  -- WRONG! Different service!
);
```

**✅ Best Practice:**

```sql
-- DO: Store reference, validate in application
CREATE TABLE orders (
    order_id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL,  -- Reference only
    -- No FK constraint
    -- Validation done via API calls to User Service
);
```

**Application-Level Validation:**

## 2. Coordinating Migrations Across Services

### Event-Driven Migration Coordination

**Saga Pattern for Schema Changes:**

**1. User Service Adds New Field:**

```sql
-- V2.0__add_loyalty_tier.sql (User Service)
ALTER TABLE users ADD COLUMN loyalty_tier VARCHAR(20) DEFAULT 'BRONZE';

-- Publish schema change event
INSERT INTO schema_change_events (
    service_name,
    migration_version,
    change_type,
    change_description,
    published_at
) VALUES (
    'user-service',
    '2.0',
    'COLUMN_ADDED',
    'Added loyalty_tier column to users table',
    CURRENT_TIMESTAMP
);
```

**2. Order Service Reacts to Schema Change:**

```java
@Service
public class SchemaChangeEventListener {
    
    @KafkaListener(topics = "schema-changes", groupId = "order-service")
    public void handleSchemaChange(SchemaChangeEvent event) {
        if (event.getServiceName().equals("user-service") 
            && event.getChangeType().equals("COLUMN_ADDED")
            && event.getChangeDescription().contains("loyalty_tier")) {
            
            // Order Service can now use loyalty_tier in pricing calculations
            log.info("User Service added loyalty_tier - updating pricing logic");
            
            // Trigger migration if needed
            if (requiresMigration(event)) {
                triggerMigration();
            }
        }
    }
    
    private boolean requiresMigration(SchemaChangeEvent event) {
        // Determine if this service needs to migrate
        return event.getVersion().compareTo(getCurrentVersion()) > 0;
    }
    
    private void triggerMigration() {
        // Trigger Flyway migration programmatically
        Flyway flyway = Flyway.configure()
            .dataSource(dataSource)
            .load();
        
        flyway.migrate();
    }
}
```

### Migration Orchestration Service

**Centralized Migration Coordinator:**

```java
@Service
public class MigrationOrchestrationService {
    
    @Autowired
    private List<MicroserviceMigrationClient> serviceClients;
    
    /**
     * Coordinate migrations across all services
     */
    public MigrationResult orchestrateMigrations(String targetVersion) {
        MigrationPlan plan = createMigrationPlan(targetVersion);
        
        // Phase 1: Backward-compatible changes
        executeMigrationPhase(plan.getBackwardCompatibleChanges());
        
        // Phase 2: Deploy new application versions
        waitForDeployments();
        
        // Phase 3: Breaking changes (after all services updated)
        executeMigrationPhase(plan.getBreakingChanges());
        
        return MigrationResult.success(targetVersion);
    }
    
    private MigrationPlan createMigrationPlan(String targetVersion) {
        MigrationPlan plan = new MigrationPlan();
        
        for (MicroserviceMigrationClient client : serviceClients) {
            ServiceMigrationInfo info = client.getMigrationInfo(targetVersion);
            
            // Separate backward-compatible from breaking changes
            plan.addBackwardCompatible(info.getBackwardCompatibleChanges());
            plan.addBreaking(info.getBreakingChanges());
        }
        
        // Resolve dependencies and order migrations
        plan.resolveDependencies();
        
        return plan;
    }
    
    private void executeMigrationPhase(List<MigrationStep> steps) {
        for (MigrationStep step : steps) {
            try {
                log.info("Executing migration: {} on {}", 
                    step.getVersion(), step.getServiceName());
                
                MicroserviceMigrationClient client = getClient(step.getServiceName());
                client.migrate(step.getVersion());
                
                log.info("Migration completed: {} on {}", 
                    step.getVersion(), step.getServiceName());
                
            } catch (Exception e) {
                log.error("Migration failed: {} on {}", 
                    step.getVersion(), step.getServiceName(), e);
                
                // Rollback strategy
                rollback(step);
                throw new MigrationFailedException(
                    "Failed to migrate " + step.getServiceName(), e);
            }
        }
    }
}
```

### Migration Status Dashboard

```java
@RestController
@RequestMapping("/api/migration")
public class MigrationStatusController {
    
    @Autowired
    private MigrationStatusService migrationStatusService;
    
    @GetMapping("/status")
    public MigrationStatusResponse getStatus() {
        List<ServiceMigrationStatus> serviceStatuses = 
            migrationStatusService.getAllServiceStatuses();
        
        return new MigrationStatusResponse(
            serviceStatuses,
            isClusterInSync(serviceStatuses),
            getOldestVersion(serviceStatuses),
            getNewestVersion(serviceStatuses)
        );
    }
    
    @GetMapping("/status/{serviceName}")
    public ServiceMigrationStatus getServiceStatus(
            @PathVariable String serviceName) {
        return migrationStatusService.getServiceStatus(serviceName);
    }
    
    private boolean isClusterInSync(List<ServiceMigrationStatus> statuses) {
        String firstVersion = statuses.get(0).getCurrentVersion();
        return statuses.stream()
            .allMatch(s -> s.getCurrentVersion().equals(firstVersion));
    }
}

@Service
public class MigrationStatusService {
    
    public List<ServiceMigrationStatus> getAllServiceStatuses() {
        List<ServiceMigrationStatus> statuses = new ArrayList<>();
        
        // Query each service's Flyway history
        for (ServiceConfig service : discoveryService.getAllServices()) {
            ServiceMigrationStatus status = getServiceStatus(service.getName());
            statuses.add(status);
        }
        
        return statuses;
    }
    
    public ServiceMigrationStatus getServiceStatus(String serviceName) {
        try {
            // Query service's database directly or via API
            ServiceDatabaseInfo dbInfo = getDatabaseInfo(serviceName);
            
            String query = """
                SELECT 
                    MAX(version) as current_version,
                    MAX(installed_on) as last_migration_time,
                    COUNT(*) as total_migrations
                FROM flyway_schema_history
                WHERE success = true
                """;
            
            JdbcTemplate jdbcTemplate = new JdbcTemplate(dbInfo.getDataSource());
            
            return jdbcTemplate.queryForObject(query, (rs, rowNum) -> 
                new ServiceMigrationStatus(
                    serviceName,
                    rs.getString("current_version"),
                    rs.getTimestamp("last_migration_time").toInstant(),
                    rs.getInt("total_migrations"),
                    ServiceStatus.HEALTHY
                )
            );
            
        } catch (Exception e) {
            return new ServiceMigrationStatus(
                serviceName,
                "unknown",
                null,
                0,
                ServiceStatus.ERROR
            );
        }
    }
}
```

### Schema-Per-Tenant Implementation

**Tenant Configuration:**

```java
@Configuration
public class MultiTenantFlywayConfig {
    
    @Autowired
    private TenantService tenantService;
    
    @Bean
    public FlywayMigrationInitializer flywayInitializer(DataSource dataSource) {
        return new FlywayMigrationInitializer() {
            @Override
            public void afterPropertiesSet() {
                List<Tenant> tenants = tenantService.getAllTenants();
                
                for (Tenant tenant : tenants) {
                    migrateTenant(tenant, dataSource);
                }
            }
        };
    }
    
    private void migrateTenant(Tenant tenant, DataSource dataSource) {
        log.info("Migrating schema for tenant: {}", tenant.getId());
        
        Flyway flyway = Flyway.configure()
            .dataSource(dataSource)
            .schemas(tenant.getSchemaName())
            .table("flyway_schema_history")  // Same table name across schemas
            .locations("classpath:db/migration/tenant")
            .baselineOnMigrate(true)
            .placeholders(Map.of(
                "tenant.id", tenant.getId(),
                "tenant.name", tenant.getName()
            ))
            .load();
        
        try {
            MigrateResult result = flyway.migrate();
            
            log.info("Tenant {} migrated: {} migrations applied", 
                tenant.getId(), result.migrationsExecuted);
            
            // Track migration status
            tenantService.updateMigrationStatus(
                tenant.getId(),
                result.targetSchemaVersion,
                MigrationStatus.SUCCESS
            );
            
        } catch (Exception e) {
            log.error("Failed to migrate tenant: {}", tenant.getId(), e);
            
            tenantService.updateMigrationStatus(
                tenant.getId(),
                null,
                MigrationStatus.FAILED
            );
            
            throw new TenantMigrationException(
                "Migration failed for tenant: " + tenant.getId(), e);
        }
    }
}
```

### New Tenant Provisioning

```java
@Service
public class TenantProvisioningService {
    
    @Autowired
    private DataSource dataSource;
    
    @Transactional
    public Tenant provisionNewTenant(TenantRequest request) {
        // 1. Create tenant record
        Tenant tenant = createTenantRecord(request);
        
        // 2. Run Flyway migrations for new tenant
        String schemaName = tenant.getId() + "_schema";
        
        Flyway flyway = Flyway.configure()
            .dataSource(dataSource)
            .schemas(schemaName)
            .createSchemas(true)  // Create schema if it doesn't exist
            .locations("classpath:db/migration/tenant")
            .placeholders(Map.of(
                "tenant.id", tenant.getId(),
                "tenant.name", tenant.getName()
            ))
            .load();
        
        try {
            // Execute all migrations for new tenant
            MigrateResult result = flyway.migrate();
            
            log.info("New tenant {} provisioned with {} migrations", 
                tenant.getId(), result.migrationsExecuted);
            
            // 3. Initialize tenant data
            initializeTenantData(tenant);
            
            return tenant;
            
        } catch (Exception e) {
            log.error("Failed to provision tenant: {}", tenant.getId(), e);
            
            // Cleanup on failure
            cleanupFailedTenant(tenant);
            
            throw new TenantProvisioningException(
                "Failed to provision tenant: " + tenant.getId(), e);
        }
    }
    
    private void initializeTenantData(Tenant tenant) {
        // Load initial data for tenant
        String schemaName = tenant.getId() + "_schema";
        
        JdbcTemplate jdbcTemplate = new JdbcTemplate(dataSource);
        
        // Set schema context
        jdbcTemplate.execute("SET search_path TO " + schemaName);
        
        // Insert default data
        jdbcTemplate.update(
            "INSERT INTO users (username, email) VALUES (?, ?)",
            "admin",
            tenant.getAdminEmail()
        );
        
        // Reset schema context
        jdbcTemplate.execute("SET search_path TO public");
    }
}
```

### Batch Tenant Migration

```java
@Service
public class BatchTenantMigrationService {
    
    @Autowired
    private TenantService tenantService;
    
    @Autowired
    private DataSource dataSource;
    
    @Async
    public CompletableFuture<BatchMigrationResult> migrateAllTenants(
            String targetVersion) {
        
        List<Tenant> tenants = tenantService.getAllTenants();
        
        log.info("Starting batch migration for {} tenants to version {}", 
            tenants.size(), targetVersion);
        
        List<TenantMigrationResult> results = new ArrayList<>();
        int successCount = 0;
        int failureCount = 0;
        
        for (Tenant tenant : tenants) {
            try {
                TenantMigrationResult result = migrateTenant(tenant, targetVersion);
                results.add(result);
                
                if (result.isSuccess()) {
                    successCount++;
                } else {
                    failureCount++;
                }
                
                // Throttle to avoid overwhelming database
                Thread.sleep(100);
                
            } catch (Exception e) {
                log.error("Failed to migrate tenant: {}", tenant.getId(), e);
                failureCount++;
            }
        }
        
        log.info("Batch migration completed: {} succeeded, {} failed", 
            successCount, failureCount);
        
        return CompletableFuture.completedFuture(
            new BatchMigrationResult(results, successCount, failureCount)
        );
    }
    
    private TenantMigrationResult migrateTenant(Tenant tenant, String targetVersion) {
        long startTime = System.currentTimeMillis();
        
        try {
            Flyway flyway = Flyway.configure()
                .dataSource(dataSource)
                .schemas(tenant.getSchemaName())
                .locations("classpath:db/migration/tenant")
                .target(targetVersion)
                .placeholders(Map.of(
                    "tenant.id", tenant.getId(),
                    "tenant.name", tenant.getName()
                ))
                .load();
            
            MigrateResult result = flyway.migrate();
            
            long duration = System.currentTimeMillis() - startTime;
            
            return new TenantMigrationResult(
                tenant.getId(),
                true,
                result.migrationsExecuted,
                result.targetSchemaVersion,
                duration,
                null
            );
            
        } catch (Exception e) {
            long duration = System.currentTimeMillis() - startTime;
            
            return new TenantMigrationResult(
                tenant.getId(),
                false,
                0,
                null,
                duration,
                e.getMessage()
            );
        }
    }
}
```

## 4. Migration Ordering in Distributed Systems

### Dependency Graph

**Service Dependencies:**

```
User Service (no dependencies)
    ↓
Order Service (depends on User Service)
    ↓
Shipping Service (depends on Order Service)
    ↓
Notification Service (depends on all above)
```

**Migration Sequence:**

### Expand-Contract Pattern for Breaking Changes

**Phase 1: Expand (Add New, Keep Old):**

**User Service - V2.0__expand_add_full_name.sql:**

```sql
-- Add new column but keep old columns
ALTER TABLE users ADD COLUMN full_name VARCHAR(200);

-- Create trigger to sync old -> new
CREATE OR REPLACE FUNCTION sync_full_name()
RETURNS TRIGGER AS $$
BEGIN
    IF NEW.full_name IS NULL THEN
        NEW.full_name := COALESCE(NEW.first_name, '') || ' ' || COALESCE(NEW.last_name, '');
    END IF;
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER users_sync_full_name
    BEFORE INSERT OR UPDATE ON users
    FOR EACH ROW
    EXECUTE FUNCTION sync_full_name();

-- Backfill existing data
UPDATE users
SET full_name = COALESCE(first_name, '') || ' ' || COALESCE(last_name, '')
WHERE full_name IS NULL;
```

**Application supports both:**

```java
@Entity
@Table(name = "users")
public class User {
    @Id
    private Long userId;
    
    // Old columns (deprecated but still supported)
    @Deprecated
    @Column(name = "first_name")
    private String firstName;
    
    @Deprecated
    @Column(name = "last_name")
    private String lastName;
    
    // New column
    @Column(name = "full_name")
    private String fullName;
    
    // Getter works with both old and new
    public String getFullName() {
        if (fullName != null) {
            return fullName;
        }
        return (firstName != null ? firstName : "") + " " + 
               (lastName != null ? lastName : "");
    }
}
```

**Phase 2: Deploy All Services:**

```
1. Deploy User Service v2.0 (supports both old and new)
2. Deploy Order Service v2.0 (uses new full_name field)
3. Deploy Shipping Service v2.0 (uses new full_name field)
4. Wait for all services to be updated
```

**Phase 3: Contract (Remove Old):**

**User Service - V3.0__contract_remove_old_names.sql:**

```sql
-- All services now use full_name, safe to remove old columns

-- Drop trigger
DROP TRIGGER IF EXISTS users_sync_full_name ON users;
DROP FUNCTION IF EXISTS sync_full_name();

-- Drop old columns
ALTER TABLE users DROP COLUMN IF EXISTS first_name;
ALTER TABLE users DROP COLUMN IF EXISTS last_name;

-- Make new column non-nullable
ALTER TABLE users ALTER COLUMN full_name SET NOT NULL;
```

```java
     * Define service dependencies for migration ordering
     */
    public Map<String, List<String>> getServiceDependencies() {
        Map<String, List<String>> dependencies = new HashMap<>();
        
        // User Service has no dependencies
        dependencies.put("user-service", List.of());
        
        // Order Service depends on User and Product services
        dependencies.put("order-service", List.of(
            "user-service",
            "product-service"
        ));
        
        // Shipping Service depends on Order Service
        dependencies.put("shipping-service", List.of(
            "order-service"
        ));
        
        // Notification Service depends on all
        dependencies.put("notification-service", List.of(
            "user-service",
            "order-service",
            "shipping-service"
        ));
        
        return dependencies;
    }
    
    /**
     * Resolve migration order using topological sort
     */
    public List<String> resolveMigrationOrder() {
        Map<String, List<String>> deps = getServiceDependencies();
        List<String> ordered = new ArrayList<>();
        Set<String> visited = new HashSet<>();
        Set<String> visiting = new HashSet<>();
        
        for (String service : deps.keySet()) {
            if (!visited.contains(service)) {
                topologicalSort(service, deps, visited, visiting, ordered);
            }
        }
        
        return ordered;
    }
    
    private void topologicalSort(
            String service,
            Map<String, List<String>> deps,
            Set<String> visited,
            Set<String> visiting,
            List<String> ordered) {
        
        if (visiting.contains(service)) {
            throw new CircularDependencyException(
                "Circular dependency detected: " + service);
        }
        
        if (visited.contains(service)) {
            return;
        }
        
        visiting.add(service);
        
        for (String dependency : deps.get(service)) {
            topologicalSort(dependency, deps, visited, visiting, ordered);
        }
        
        visiting.remove(service);
        visited.add(service);
        ordered.add(service);
    }
}
```

### Migration with Dependency Checks

```java
@Service
public class DependencyAwareMigrationService {
    
    @Autowired
    private ServiceDependencyConfig dependencyConfig;
    
    @Autowired
    private ServiceDiscoveryClient discoveryClient;
    
    public void migrateWithDependencyCheck(String serviceName, String targetVersion) {
        // Check all dependencies are at compatible versions
        List<String> dependencies = dependencyConfig
            .getServiceDependencies()
            .get(serviceName);
        
        for (String dependency : dependencies) {
            ServiceVersion depVersion = discoveryClient
                .getServiceVersion(dependency);
            
            if (!isCompatible(targetVersion, depVersion)) {
                throw new IncompatibleVersionException(
                    String.format(
                        "Cannot migrate %s to %s: dependency %s is at incompatible version %s",
                        serviceName, targetVersion, dependency, depVersion
                    )
                );
            }
        }
        
        // All dependencies compatible, proceed with migration
        executeMigration(serviceName, targetVersion);
    }
    
    private boolean isCompatible(String serviceVersion, ServiceVersion dependencyVersion) {
        // Check version compatibility
        // Example: Service 2.0 requires dependency >= 1.5
        VersionRequirement requirement = getVersionRequirement(serviceVersion);
        return requirement.isSatisfiedBy(dependencyVersion);
    }
}
```

### Circuit Breaker for Migration Failures

```java
@Service
public class ResilientMigrationService {
    
    @Autowired
    private CircuitBreakerFactory circuitBreakerFactory;
    
    public MigrationResult migrateWithCircuitBreaker(
            String serviceName, 
            String targetVersion) {
        
        CircuitBreaker circuitBreaker = circuitBreakerFactory
            .create(serviceName + "-migration");
        
        return circuitBreaker.run(
            () -> executeMigration(serviceName, targetVersion),
            throwable -> handleMigrationFailure(serviceName, targetVersion, throwable)
        );
    }
    
    private MigrationResult executeMigration(String serviceName, String targetVersion) {
        log.info("Migrating {} to version {}", serviceName, targetVersion);
        
        // Execute Flyway migration
        Flyway flyway = getFlywayForService(serviceName);
        MigrateResult result = flyway.migrate();
        
        return new MigrationResult(
            serviceName,
            targetVersion,
            result.migrationsExecuted,
            MigrationStatus.SUCCESS
        );
    }
    
    private MigrationResult handleMigrationFailure(
            String serviceName,
            String targetVersion,
            Throwable throwable) {
        
        log.error("Migration failed for {}: {}", serviceName, throwable.getMessage());
        
        // Attempt rollback
        try {
            rollbackMigration(serviceName);
        } catch (Exception e) {
            log.error("Rollback also failed for {}", serviceName, e);
        }
        
        return new MigrationResult(
            serviceName,
            targetVersion,
            0,
            MigrationStatus.FAILED
        );
    }
}
```

## 6. Version Compatibility

### Semantic Versioning for Schemas

**Version Format: MAJOR.MINOR.PATCH**

```
MAJOR: Breaking changes (incompatible API changes)
MINOR: New features (backward-compatible)
PATCH: Bug fixes (backward-compatible)

Examples:
1.0.0 → 1.1.0  (Added column, backward-compatible)
1.1.0 → 2.0.0  (Removed column, BREAKING)
2.0.0 → 2.0.1  (Fixed constraint, backward-compatible)
```

### Version Compatibility Matrix

```java
@Configuration

        CompatibilityMatrix matrix = new CompatibilityMatrix();
        
        // User Service version requirements
        matrix.addRequirement(

        );
        
        matrix.addRequirement(

            "user-service", ">= 1.0.0"
        );
        
        return matrix;
    }
}

public class CompatibilityMatrix {
    
    private Map<ServiceVersionPair, VersionRequirement> requirements = new HashMap<>();
    
    public void addRequirement(
            String serviceName,
            String serviceVersion,
            String dependencyName,
            String versionRequirement) {
        
        ServiceVersionPair key = new ServiceVersionPair(serviceName, serviceVersion);
        requirements.put(key, new VersionRequirement(dependencyName, versionRequirement));
    }
    
    public boolean isCompatible(
            String serviceName,
            String serviceVersion,
            Map<String, String> availableVersions) {
        
        ServiceVersionPair key = new ServiceVersionPair(serviceName, serviceVersion);
        VersionRequirement requirement = requirements.get(key);
        
        if (requirement == null) {
            return true;  // No specific requirement
        }
        
        String availableVersion = availableVersions.get(requirement.getServiceName());
        return requirement.isSatisfiedBy(availableVersion);
    }
}
```

### Backward Compatibility Validation

```java
@Component
public class BackwardCompatibilityValidator implements Callback {
    
    @Override
    public boolean supports(Event event, Context context) {
        return event == Event.BEFORE_MIGRATE;
    }
    
    @Override
    public boolean canHandleInTransaction(Event event, Context context) {
        return true;
    }
    
    @Override
    public void handle(Event event, Context context) {
        try {
            validateBackwardCompatibility(context);
        } catch (IncompatibleSchemaException e) {
            throw new FlywayException(
                "Migration blocked: " + e.getMessage(), e);
        }
    }
    
    private void validateBackwardCompatibility(Context context) throws Exception {
        // Get current version
        String currentVersion = getCurrentVersion(context);
        
        // Get pending migrations
        List<MigrationInfo> pendingMigrations = getPendingMigrations(context);
        
        for (MigrationInfo migration : pendingMigrations) {
            // Check if migration is breaking
            if (isBreakingChange(migration)) {
                // Verify all dependent services are ready
                if (!allDependentsReady(migration.getVersion())) {
                    throw new IncompatibleSchemaException(
                        String.format(
                            "Cannot apply breaking migration %s: " +
                            "dependent services not ready",
                            migration.getVersion()
                        )
                    );
                }
            }
        }
    }
    
    private boolean isBreakingChange(MigrationInfo migration) {
        // Parse version
        Version version = Version.parse(migration.getVersion());
        Version current = getCurrentSchemaVersion();
        
        // Major version change = breaking
        return version.getMajor() > current.getMajor();
    }
    
    @Override
    public String getCallbackName() {
        return "BackwardCompatibilityValidator";
    }
}
```

```java
            return;

            executeMigration(serviceName, targetVersion);

            featureFlagService.markComplete(featureFlag);

            // Migration failed, disable flag
            featureFlagService.disable(featureFlag);
            
            log.error("Migration failed, disabled feature flag: {}", featureFlag);
            throw e;
        }
    }
}
```

## Best Practices Summary

### ✅ DO:

1. **Use database-per-service** pattern for true independence
2. **Avoid cross-service foreign keys** - validate in application
3. **Coordinate migrations** for interdependent services
4. **Use schema-per-tenant** for multi-tenant applications
5. **Order migrations** based on service dependencies
6. **Use expand-contract** pattern for breaking changes
7. **Version schemas** using semantic versioning
8. **Track compatibility** in version metadata
9. **Validate backward compatibility** before migration
10. **Use feature flags** for gradual rollout

### ❌ DON'T:

1. **Don't share databases** between services (violates boundaries)
2. **Don't create cross-service constraints** (couples services)
3. **Don't migrate in random order** (breaks dependencies)
4. **Don't apply breaking changes** without coordination
5. **Don't skip version checks** (causes compatibility issues)
6. **Don't use same schema** for all tenants (security risk)
7. **Don't ignore service dependencies** (causes failures)
8. **Don't forget rollback strategy** (no recovery path)
9. **Don't deploy breaking changes** without expand-contract
10. **Don't skip monitoring** of migration status

## Interview Questions

**Q1: How do you handle database migrations in a microservices architecture?**

Each service owns its database and Flyway instance. Services migrate independently but coordinate for interdependent changes. Use expand-contract pattern for breaking changes: expand (add new, keep old), deploy all services, contract (remove old). Avoid cross-service foreign keys; validate referential integrity in application code.

**Q2: What's the expand-contract pattern and when do you use it?**

Expand-contract enables zero-downtime schema changes: (1) Expand - add new schema elements while keeping old ones, (2) Deploy application versions supporting both schemas, (3) Contract - remove old schema elements after all services updated. Use for breaking changes like renaming columns or removing tables.

**Q3: How do you handle schema-per-tenant migrations?**

Configure Flyway to run migrations for each tenant's schema using placeholders for tenant-specific values. For new tenant provisioning, create schema and run all migrations. For existing tenants, batch migrate all schemas with throttling to avoid database overload. Track migration status per tenant.

**Q4: How do you prevent migration failures due to service dependencies?**

Define dependency graph for services, use topological sort to determine migration order, validate dependencies before migration using compatibility matrix, implement circuit breakers for resilience, and use version metadata to track compatibility requirements between services.

**Q5: How do you maintain version compatibility across microservices?**

Use semantic versioning (MAJOR.MINOR.PATCH) for schema versions, maintain compatibility matrix defining version requirements, store version metadata in database, validate backward compatibility before migrations, use feature flags for gradual rollout, and coordinate breaking changes across all dependent services.
