# Redis as a Session Store

## Overview

Redis is an excellent choice for distributed session management, enabling stateless applications with session data shared across multiple instances. Spring Session with Redis provides transparent session management with minimal code changes, automatic session replication, and flexible expiration policies. This enables horizontal scaling and zero-downtime deployments.

**Key Concept**: Use Spring Session with Redis to externalize HTTP sessions from application memory to Redis. Configure @EnableRedisHttpSession for automatic session management. Choose appropriate serialization (JSON for debugging, JDK for compatibility). Set session timeout based on security requirements (30 minutes typical). Sessions automatically replicate across cluster instances, enabling stateless applications and seamless failover.

```java
     * Store data in session
     */
    @PostMapping("/store")
    public ResponseEntity<String> storeInSession(
            @RequestParam String key,
            @RequestParam String value,
            HttpSession session) {
        
        session.setAttribute(key, value);
        
        log.info("Stored in session - ID: {}, Key: {}, Value: {}", 
            session.getId(), key, value);
        
        return ResponseEntity.ok("Stored in session");
    }
    
    /**
     * Retrieve data from session
     */
    @GetMapping("/retrieve")
    public ResponseEntity<Object> retrieveFromSession(
            @RequestParam String key,
            HttpSession session) {
        
        Object value = session.getAttribute(key);
        
        log.info("Retrieved from session - ID: {}, Key: {}, Value: {}", 
            session.getId(), key, value);
        
        return ResponseEntity.ok(value);
    }
    
    /**
     * Get session information
     */
    @GetMapping("/info")
    public ResponseEntity<Map<String, Object>> getSessionInfo(HttpSession session) {
        Map<String, Object> info = new HashMap<>();
        
        info.put("sessionId", session.getId());
        info.put("creationTime", new Date(session.getCreationTime()));
        info.put("lastAccessedTime", new Date(session.getLastAccessedTime()));
        info.put("maxInactiveInterval", session.getMaxInactiveInterval());
        info.put("isNew", session.isNew());
        
        // Get all attributes
        Map<String, Object> attributes = new HashMap<>();
        Enumeration<String> attributeNames = session.getAttributeNames();
        
        while (attributeNames.hasMoreElements()) {
            String name = attributeNames.nextElement();
            attributes.put(name, session.getAttribute(name));
        }
        
        info.put("attributes", attributes);
        
        return ResponseEntity.ok(info);
    }
    
    /**
     * Remove attribute from session
     */
    @DeleteMapping("/remove")
    public ResponseEntity<String> removeFromSession(
            @RequestParam String key,
            HttpSession session) {
        
        session.removeAttribute(key);
        
        log.info("Removed from session - ID: {}, Key: {}", session.getId(), key);
        
        return ResponseEntity.ok("Removed from session");
    }
    
    /**
     * Invalidate session
     */
    @PostMapping("/invalidate")
    public ResponseEntity<String> invalidateSession(HttpSession session) {
        String sessionId = session.getId();
        
        session.invalidate();
        
        log.info("Session invalidated - ID: {}", sessionId);
        
        return ResponseEntity.ok("Session invalidated");
    }
    
    /**
     * Update session timeout
     */
    @PostMapping("/timeout")
    public ResponseEntity<String> updateTimeout(
            @RequestParam int minutes,
            HttpSession session) {
        
        session.setMaxInactiveInterval(minutes * 60);
        
        log.info("Session timeout updated - ID: {}, Minutes: {}", 
            session.getId(), minutes);
        
        return ResponseEntity.ok("Timeout updated to " + minutes + " minutes");
```

### Custom Serialization

**Specialized Serializer:**

```java
@Configuration
@EnableRedisHttpSession
public class CustomSerializationConfig {

            EncryptionService encryptionService) {

    }
}

/**
 * Custom serializer with encryption
 */
public class EncryptedRedisSerializer implements RedisSerializer<Object> {
    
    private final EncryptionService encryptionService;
    private final GenericJackson2JsonRedisSerializer jsonSerializer;
    
    public EncryptedRedisSerializer(EncryptionService encryptionService) {
        this.encryptionService = encryptionService;
        this.jsonSerializer = new GenericJackson2JsonRedisSerializer();
    }
    
    @Override
    public byte[] serialize(Object value) throws SerializationException {
        if (value == null) {
            return new byte[0];
        }
        
        try {
            // Serialize to JSON
            byte[] jsonBytes = jsonSerializer.serialize(value);
            
            // Encrypt
            return encryptionService.encrypt(jsonBytes);
            
        } catch (Exception e) {
            throw new SerializationException("Failed to serialize and encrypt", e);
        }
    }
    
    @Override
    public Object deserialize(byte[] bytes) throws SerializationException {
        if (bytes == null || bytes.length == 0) {
            return null;
        }
        
        try {
            // Decrypt
            byte[] decryptedBytes = encryptionService.decrypt(bytes);
            
            // Deserialize from JSON
            return jsonSerializer.deserialize(decryptedBytes);
            
        } catch (Exception e) {
            throw new SerializationException("Failed to decrypt and deserialize", e);
        }
    }
}

@Service
public class EncryptionService {
    
    private static final String ALGORITHM = "AES/GCM/NoPadding";
    private final SecretKey secretKey;
    
    public EncryptionService(@Value("${session.encryption.key}") String keyString) 
            throws Exception {
        
        byte[] keyBytes = Base64.getDecoder().decode(keyString);
        this.secretKey = new SecretKeySpec(keyBytes, "AES");
    }
    
    public byte[] encrypt(byte[] data) throws Exception {
        Cipher cipher = Cipher.getInstance(ALGORITHM);
        
        // Generate random IV
        byte[] iv = new byte[12];
        SecureRandom random = new SecureRandom();
        random.nextBytes(iv);
        
        GCMParameterSpec gcmSpec = new GCMParameterSpec(128, iv);
        cipher.init(Cipher.ENCRYPT_MODE, secretKey, gcmSpec);
        
        byte[] encrypted = cipher.doFinal(data);
        
        // Prepend IV to encrypted data
        byte[] result = new byte[iv.length + encrypted.length];
        System.arraycopy(iv, 0, result, 0, iv.length);
        System.arraycopy(encrypted, 0, result, iv.length, encrypted.length);
        
        return result;
    }
    
    public byte[] decrypt(byte[] data) throws Exception {
        Cipher cipher = Cipher.getInstance(ALGORITHM);
        
        // Extract IV
        byte[] iv = new byte[12];
        System.arraycopy(data, 0, iv, 0, iv.length);
        
        // Extract encrypted data
        byte[] encrypted = new byte[data.length - iv.length];
        System.arraycopy(data, iv.length, encrypted, 0, encrypted.length);
        
        GCMParameterSpec gcmSpec = new GCMParameterSpec(128, iv);
        cipher.init(Cipher.DECRYPT_MODE, secretKey, gcmSpec);
        
        return cipher.doFinal(encrypted);
    }
}
```

```java
@Service
@Slf4j
public class SessionTimeoutService {
    
    /**
     * Set session timeout dynamically
     */
    public void setSessionTimeout(HttpSession session, Duration timeout) {
        session.setMaxInactiveInterval((int) timeout.getSeconds());
        
        log.info("Session timeout set - ID: {}, Timeout: {} seconds",
            session.getId(), timeout.getSeconds());
    }
    
    /**
     * Extend session timeout
     */
    public void extendSession(HttpSession session, Duration extension) {
        int currentTimeout = session.getMaxInactiveInterval();
        int newTimeout = currentTimeout + (int) extension.getSeconds();
        
        session.setMaxInactiveInterval(newTimeout);
        
        log.info("Session extended - ID: {}, New timeout: {} seconds",
            session.getId(), newTimeout);
    }
    
    /**
     * Get remaining session time
     */
    public Duration getRemainingTime(HttpSession session) {
        long lastAccessed = session.getLastAccessedTime();
        int maxInactive = session.getMaxInactiveInterval();
        
        long now = System.currentTimeMillis();
        long elapsed = (now - lastAccessed) / 1000;  // seconds
        long remaining = maxInactive - elapsed;
        
        return Duration.ofSeconds(Math.max(0, remaining));
    }
    
    /**
     * Check if session is about to expire
     */
    public boolean isSessionExpiringSoon(HttpSession session, Duration threshold) {
        Duration remaining = getRemainingTime(session);
        return remaining.compareTo(threshold) < 0;
    }
}
```

### Idle Timeout vs Absolute Timeout

**Implementing Both:**

```java
@Configuration
@EnableRedisHttpSession(maxInactiveIntervalInSeconds = 1800) // 30 min idle
public class TimeoutConfiguration {
    
    /**
     * Session filter for absolute timeout
     */
    @Bean
    public FilterRegistrationBean<AbsoluteTimeoutFilter> absoluteTimeoutFilter() {
        FilterRegistrationBean<AbsoluteTimeoutFilter> registration = 
            new FilterRegistrationBean<>();
        
        registration.setFilter(new AbsoluteTimeoutFilter());
        registration.addUrlPatterns("/*");
        registration.setOrder(1);
        
        return registration;
    }
}

/**
 * Filter to enforce absolute session timeout
 */
@Slf4j
public class AbsoluteTimeoutFilter implements Filter {
    
    private static final long ABSOLUTE_TIMEOUT_MS = 4 * 60 * 60 * 1000; // 4 hours
    
    @Override
    public void doFilter(
            ServletRequest request,
            ServletResponse response,
            FilterChain chain) throws IOException, ServletException {
        
        HttpServletRequest httpRequest = (HttpServletRequest) request;
        HttpSession session = httpRequest.getSession(false);
        
        if (session != null) {
            Long creationTime = (Long) session.getAttribute("absoluteCreationTime");
            
            if (creationTime == null) {
                // First access - record creation time
                session.setAttribute("absoluteCreationTime", System.currentTimeMillis());
            } else {
                // Check absolute timeout
                long elapsed = System.currentTimeMillis() - creationTime;
                
                if (elapsed > ABSOLUTE_TIMEOUT_MS) {
                    log.warn("Session {} exceeded absolute timeout", session.getId());
                    session.invalidate();
                    
                    HttpServletResponse httpResponse = (HttpServletResponse) response;
                    httpResponse.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
                    httpResponse.getWriter().write("Session expired (absolute timeout)");
                    return;
                }
            }
        }
        
        chain.doFilter(request, response);
    }
}
```

### Session Cleanup

**Custom Cleanup Strategy:**

```java
@Service
@Slf4j
public class SessionCleanupService {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    public SessionCleanupService(RedisTemplate<String, Object> redisTemplate) {
        this.redisTemplate = redisTemplate;
    }
    
    /**
     * Scheduled cleanup of expired sessions
     * (Spring Session handles this automatically, but here's how to do it manually)
     */
    @Scheduled(cron = "0 0 * * * *")  // Every hour
    public void cleanupExpiredSessions() {
        String pattern = "spring:session:sessions:expires:*";
        
        Set<String> expiredKeys = redisTemplate.keys(pattern);
        
        if (expiredKeys != null && !expiredKeys.isEmpty()) {
            long now = System.currentTimeMillis();
            
            expiredKeys.forEach(key -> {
                Long expireTime = (Long) redisTemplate.opsForValue().get(key);
                
                if (expireTime != null && expireTime < now) {
                    // Extract session ID and delete
                    String sessionId = extractSessionId(key);
                    deleteSession(sessionId);
                }
            });
            
            log.info("Cleaned up {} expired sessions", expiredKeys.size());
        }
    }
    
    private String extractSessionId(String key) {
        // Extract session ID from key pattern
        return key.substring(key.lastIndexOf(':') + 1);
    }
    
    private void deleteSession(String sessionId) {
        // Delete all keys associated with session
        String[] patterns = {
            "spring:session:sessions:" + sessionId,
            "spring:session:sessions:expires:" + sessionId,
            "spring:session:expirations:" + sessionId
        };
        
        for (String pattern : patterns) {
            redisTemplate.delete(pattern);
        }
        
        log.debug("Deleted session: {}", sessionId);
    }
}
```

### Session Encryption

**Encrypt Sensitive Session Data:**

```java
@Service
@RequiredArgsConstructor
public class SecureSessionService {
    
    private final EncryptionService encryptionService;
    
    /**
     * Store encrypted data in session
     */
    public void storeSecureData(HttpSession session, String key, String value) {
        try {
            String encrypted = encryptionService.encryptString(value);
            session.setAttribute(key, encrypted);
            
        } catch (Exception e) {
            throw new IllegalStateException("Failed to encrypt session data", e);
        }
    }
    
    /**
     * Retrieve and decrypt data from session
     */
    public String getSecureData(HttpSession session, String key) {
        try {
            String encrypted = (String) session.getAttribute(key);
            
            if (encrypted == null) {
                return null;
            }
            
            return encryptionService.decryptString(encrypted);
            
        } catch (Exception e) {
            throw new IllegalStateException("Failed to decrypt session data", e);
        }
    }
    
    /**
     * Store sensitive user data
     */
    public void storeSensitiveUserData(HttpSession session, SensitiveUserData data) {
        // Only store non-sensitive identifiers in clear
        session.setAttribute("userId", data.getUserId());
        
        // Encrypt sensitive fields
        storeSecureData(session, "ssn", data.getSsn());
        storeSecureData(session, "creditCard", data.getCreditCard());
        storeSecureData(session, "password", data.getPassword());
    }
}
```

### Session Hijacking Prevention

**Additional Security Measures:**

```java
@Component
@Slf4j
public class SessionSecurityFilter implements Filter {
    
    @Override
    public void doFilter(
            ServletRequest request,
            ServletResponse response,
            FilterChain chain) throws IOException, ServletException {
        
        HttpServletRequest httpRequest = (HttpServletRequest) request;
        HttpSession session = httpRequest.getSession(false);
        
        if (session != null) {
            // Verify IP address hasn't changed
            String currentIp = httpRequest.getRemoteAddr();
            String sessionIp = (String) session.getAttribute("ipAddress");
            
            if (sessionIp == null) {
                session.setAttribute("ipAddress", currentIp);
            } else if (!sessionIp.equals(currentIp)) {
                log.warn("Session {} IP changed from {} to {}", 
                    session.getId(), sessionIp, currentIp);
                
                session.invalidate();
                
                HttpServletResponse httpResponse = (HttpServletResponse) response;
                httpResponse.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
                httpResponse.getWriter().write("Session invalidated: IP mismatch");
                return;
            }
            
            // Verify User-Agent hasn't changed
            String currentUserAgent = httpRequest.getHeader("User-Agent");
            String sessionUserAgent = (String) session.getAttribute("userAgent");
            
            if (sessionUserAgent == null) {
                session.setAttribute("userAgent", currentUserAgent);
            } else if (!sessionUserAgent.equals(currentUserAgent)) {
                log.warn("Session {} User-Agent changed", session.getId());
                
                session.invalidate();
                
                HttpServletResponse httpResponse = (HttpServletResponse) response;
                httpResponse.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
                httpResponse.getWriter().write("Session invalidated: User-Agent mismatch");
                return;
            }
        }
        
        chain.doFilter(request, response);
    }
}
```

```java
@RestController
@RequestMapping("/api/sessions")
@RequiredArgsConstructor
public class SessionManagementController {
    
    private final SessionRegistry sessionRegistry;
    private final SessionRepository sessionRepository;
    
    /**
     * Get all active sessions for current user
     */
    @GetMapping("/active")
    public ResponseEntity<List<Map<String, Object>>> getActiveSessions(
            Authentication authentication) {
        
        List<SessionInformation> sessions = sessionRegistry.getAllSessions(
            authentication.getPrincipal(),
            false  // includeExpiredSessions
        );
        
        List<Map<String, Object>> sessionList = sessions.stream()
            .map(sessionInfo -> Map.of(
                "sessionId", sessionInfo.getSessionId(),
                "lastRequest", sessionInfo.getLastRequest(),
                "expired", sessionInfo.isExpired()
            ))
            .collect(Collectors.toList());
        
        return ResponseEntity.ok(sessionList);
    }
    
    /**
     * Invalidate specific session
     */
    @DeleteMapping("/{sessionId}")
    public ResponseEntity<String> invalidateSession(@PathVariable String sessionId) {
        sessionRepository.deleteById(sessionId);
        return ResponseEntity.ok("Session invalidated");
    }
    
    /**
     * Invalidate all sessions except current
     */
    @PostMapping("/invalidate-others")
    public ResponseEntity<String> invalidateOtherSessions(
            Authentication authentication,
            HttpSession currentSession) {
        
        List<SessionInformation> sessions = sessionRegistry.getAllSessions(
            authentication.getPrincipal(),
            false
        );
        
        sessions.stream()
            .filter(s -> !s.getSessionId().equals(currentSession.getId()))
            .forEach(s -> {
                sessionRepository.deleteById(s.getSessionId());
                s.expireNow();
            });
        
        return ResponseEntity.ok("Other sessions invalidated");
    }
}
```

## Interview Questions

**Q1: How does Spring Session with Redis enable stateless applications?**

Spring Session externalizes HTTP session from application memory to Redis. Multiple application instances share same Redis, so any instance can handle any request. Session data automatically replicated across cluster. When user makes request: (1) Load balancer forwards to any instance, (2) Instance retrieves session from Redis using session ID from cookie, (3) Application processes request with session data, (4) Changes saved back to Redis. No sticky sessions needed. Enables horizontal scaling, zero-downtime deployments, seamless failover.

**Q2: What are the different session serialization strategies and when to use each?**

JDK Serialization (default): Works with Serializable objects, not human-readable, larger size, versioning issues. Use for: compatibility with existing code. JSON Serialization: Human-readable, smaller size, language-agnostic, easier debugging, requires type information handling. Use for: new applications, debugging needs. Custom/Encrypted: Application-specific logic, can add encryption, compression. Use for: sensitive data, special requirements. Recommendation: Use JSON (GenericJackson2JsonRedisSerializer) for new apps - readable, efficient, debuggable.

**Q3: How do you implement session timeout in Spring Session?**

Two timeout types: (1) Idle timeout - time since last activity. Configure with `@EnableRedisHttpSession(maxInactiveIntervalInSeconds = 1800)` or `spring.session.timeout=30m`. Session extends on each access. (2) Absolute timeout - time since creation. Implement custom filter tracking creation time. Session management: Programmatically set with `session.setMaxInactiveInterval(seconds)`. Get remaining time from lastAccessedTime. Cleanup: Spring Session auto-cleanup with cron expression. Monitor with session events (created, deleted, expired).

**Q4: What security considerations are important for session management?**

Critical security measures: (1) Session fixation - use migrateSession on authentication to prevent attack. (2) Cookie security - HttpOnly (prevent XSS), Secure (HTTPS only), SameSite (CSRF protection). (3) Encryption - encrypt sensitive session data. (4) Session hijacking - validate IP/User-Agent consistency. (5) Concurrent sessions - limit active sessions per user. (6) CSRF protection - use tokens. (7) Timeout - reasonable timeout (30 min), absolute timeout for sensitive operations. (8) HTTPS only - never transmit session cookies over HTTP.

**Q5: How does session replication work in a clustered environment?**

With Redis session store: (1) User authenticates on Instance A, (2) Session data stored in Redis (not instance memory), (3) Session ID returned to browser in cookie, (4) Next request goes to Instance B via load balancer, (5) Instance B reads session ID from cookie, (6) Instance B fetches session from Redis, (7) Processes request with session data, (8) Updates saved to Redis. Key benefits: No sticky sessions needed, true stateless apps, automatic failover, zero-downtime deploys. All instances share same Redis. Use same namespace and serializer across all instances. Session available immediately to all instances.
