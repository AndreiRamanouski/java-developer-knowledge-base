# Redis Persistence and High Availability

## Overview

Redis provides multiple mechanisms for data persistence, replication, and high availability. RDB snapshots offer point-in-time backups, while AOF logs every write operation for durability. Redis Sentinel provides automatic failover and monitoring for master-replica setups. Redis Cluster enables horizontal scaling with automatic sharding. Proper configuration ensures zero data loss, automatic recovery, and 99.99% uptime in production.

**Key Concept**: Redis is in-memory but provides persistence. Use RDB for periodic snapshots (faster restart, smaller files) or AOF for durability (minimal data loss). Sentinel for HA in single-master setups (automatic failover). Cluster for horizontal scaling with sharding (16,384 hash slots). Always configure replication (1 master + 2+ replicas) for production. Combine RDB + AOF for best durability and performance.

## 1. RDB vs AOF Persistence

### Understanding Persistence Mechanisms

**Comparison Matrix:**

```
┌──────────────────────────────────────────────────────────────────────────┐
│                    RDB vs AOF Persistence                                 │
├────────────────────┬──────────────────────┬───────────────────────────────┤
│ Feature            │ RDB (Snapshot)       │ AOF (Append-Only File)        │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ What is it?        │ Point-in-time        │ Log of write operations       │
│                    │ binary snapshot      │ (replay on restart)           │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ Data Loss Risk     │ Higher               │ Lower                         │
│                    │ (last save to crash) │ (1 sec or better)             │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ File Size          │ Smaller              │ Larger                        │
│                    │ (compressed binary)  │ (text logs)                   │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ Write Performance  │ Faster               │ Slower                        │
│                    │ (background fork)    │ (log every write)             │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ Restart Speed      │ Faster               │ Slower                        │
│                    │ (load binary)        │ (replay commands)             │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ CPU Usage          │ Lower                │ Higher                        │
│                    │ (periodic saves)     │ (continuous writes)           │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ Disk I/O           │ Burst               │ Continuous                    │
│                    │ (during save)        │ (every write)                 │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ Corruption Risk    │ Lower                │ Higher                        │
│                    │ (atomic writes)      │ (append failures)             │
├────────────────────┼──────────────────────┼───────────────────────────────┤
│ Use Case           │ • Periodic backups   │ • Maximum durability          │
│                    │ • Fast restarts      │ • Minimal data loss           │
│                    │ • Read-heavy apps    │ • Write-heavy apps            │
│                    │ • Cache scenarios    │ • Transactional data          │
└────────────────────┴──────────────────────┴───────────────────────────────┘

Recommendation: Use BOTH (RDB + AOF) for production
- RDB for faster restarts and backups
- AOF for durability and minimal data loss
```

**Programmatic RDB Operations:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class RedisBackupService {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    /**
     * Trigger synchronous save (blocks until complete)
     * Use sparingly - blocks Redis server
     */
    public void saveSync() {
        try {
            redisTemplate.getConnectionFactory()
                .getConnection()
                .save();
            
            log.info("Synchronous RDB save completed");
            
        } catch (Exception e) {
            log.error("Failed to save RDB", e);
            throw new RuntimeException("RDB save failed", e);
        }
    }
    
    /**
     * Trigger background save (non-blocking)
     * Preferred method
     */
    public void saveAsync() {
        try {
            redisTemplate.getConnectionFactory()
                .getConnection()
                .bgSave();
            
            log.info("Background RDB save initiated");
            
        } catch (Exception e) {
            log.error("Failed to initiate background save", e);
            throw new RuntimeException("Background save failed", e);
        }
    }
    
    /**
     * Get last save time
     */
    public LocalDateTime getLastSaveTime() {
        try {
            Long lastSaveTimestamp = redisTemplate.getConnectionFactory()
                .getConnection()
                .lastSave();
            
            return LocalDateTime.ofInstant(
                Instant.ofEpochSecond(lastSaveTimestamp),
                ZoneId.systemDefault()
            );
            
        } catch (Exception e) {
            log.error("Failed to get last save time", e);
            return null;
        }
    }
    
    /**
     * Scheduled backup
     */
    @Scheduled(cron = "0 0 2 * * *")  // 2 AM daily
    public void scheduledBackup() {
        log.info("Starting scheduled RDB backup");
        
        saveAsync();
        
        // Optional: Copy RDB file to backup location
        LocalDateTime saveTime = getLastSaveTime();
        log.info("RDB backup initiated. Last save: {}", saveTime);
    }
}
```

### AOF Configuration

**Redis Configuration (redis.conf):**

```conf
# AOF Persistence Configuration

# Enable AOF
appendonly yes

# AOF filename
appendfilename "appendonly.aof"

# Fsync policy (durability vs performance)
# always  - fsync after every write (slowest, most durable)
# everysec - fsync every second (good balance) - RECOMMENDED
# no      - let OS decide when to fsync (fastest, least durable)
appendfsync everysec

# Rewrite AOF when it grows too large
# Automatically triggered when AOF is 100% larger than base size
auto-aof-rewrite-percentage 100
auto-aof-rewrite-min-size 64mb

# Don't fsync during rewrite (better performance)
no-appendfsync-on-rewrite no

# Load truncated AOF on startup (corruption recovery)
aof-load-truncated yes

# Use RDB-AOF hybrid format (Redis 4.0+)
# AOF file starts with RDB snapshot, then appends operations
# Faster loading, smaller files
aof-use-rdb-preamble yes
```

**AOF Operations:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class AofManagementService {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    /**
     * Trigger AOF rewrite (compaction)
     * Rebuilds AOF file from current dataset
     */
    public void rewriteAof() {
        try {
            redisTemplate.getConnectionFactory()
                .getConnection()
                .bgReWriteAof();
            
            log.info("AOF rewrite initiated");
            
        } catch (Exception e) {
            log.error("Failed to initiate AOF rewrite", e);
            throw new RuntimeException("AOF rewrite failed", e);
        }
    }
    
    /**
     * Get AOF info
     */
    public Map<String, String> getAofInfo() {
        try {
            Properties info = redisTemplate.getConnectionFactory()
                .getConnection()
                .info("persistence");
            
            Map<String, String> aofInfo = new HashMap<>();
            aofInfo.put("aof_enabled", info.getProperty("aof_enabled"));
            aofInfo.put("aof_current_size", info.getProperty("aof_current_size"));
            aofInfo.put("aof_base_size", info.getProperty("aof_base_size"));
            aofInfo.put("aof_last_rewrite_time_sec", 
                info.getProperty("aof_last_rewrite_time_sec"));
            
            return aofInfo;
            
        } catch (Exception e) {
            log.error("Failed to get AOF info", e);
            return Collections.emptyMap();
        }
    }
    
    /**
     * Monitor AOF size and trigger rewrite if needed
     */
    @Scheduled(fixedRate = 3600000)  // Every hour
    public void monitorAofSize() {
        Map<String, String> info = getAofInfo();
        
        if (info.isEmpty()) {
            return;
        }
        
        long currentSize = Long.parseLong(info.getOrDefault("aof_current_size", "0"));
        long baseSize = Long.parseLong(info.getOrDefault("aof_base_size", "0"));
        
        // Trigger rewrite if current size is 2x base size
        if (baseSize > 0 && currentSize > baseSize * 2) {
            log.warn("AOF file is {}x larger than base. Triggering rewrite.", 
                currentSize / baseSize);
            
            rewriteAof();
        }
    }
}
```

```java
@Component
@RequiredArgsConstructor
@Slf4j
public class RedisPersistenceHealthIndicator implements HealthIndicator {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    @Override
    public Health health() {
        try {
            Properties info = redisTemplate.getConnectionFactory()
                .getConnection()
                .info("persistence");
            
            Map<String, Object> details = new HashMap<>();
            
            // RDB info
            details.put("rdb_last_save_time", info.getProperty("rdb_last_save_time"));
            details.put("rdb_last_save_status", info.getProperty("rdb_last_bgsave_status"));
            
            // AOF info
            details.put("aof_enabled", info.getProperty("aof_enabled"));
            details.put("aof_last_rewrite_status", 
                info.getProperty("aof_last_rewrite_status"));
            
            // Check for errors
            String rdbStatus = info.getProperty("rdb_last_bgsave_status", "ok");
            String aofStatus = info.getProperty("aof_last_rewrite_status", "ok");
            
            if ("ok".equals(rdbStatus) && "ok".equals(aofStatus)) {
                return Health.up().withDetails(details).build();
            } else {
                return Health.down().withDetails(details).build();
            }
            
        } catch (Exception e) {
            return Health.down().withException(e).build();
        }
    }
}
```

**Java Configuration:**

```java
@Configuration
public class RedisSentinelConfig {
    
    @Value("${spring.data.redis.sentinel.master}")
    private String masterName;
    
    @Value("${spring.data.redis.password:}")
    private String password;
    
    /**
     * Lettuce connection factory with Sentinel
     */
    @Bean
    public LettuceConnectionFactory redisConnectionFactory() {
        // Sentinel configuration
        RedisSentinelConfiguration sentinelConfig = 
            new RedisSentinelConfiguration()
                .master(masterName)
                .sentinel("localhost", 26379)
                .sentinel("localhost", 26380)
                .sentinel("localhost", 26381);
        
        if (password != null && !password.isEmpty()) {
            sentinelConfig.setPassword(password);
        }
        
        // Pool configuration
        GenericObjectPoolConfig<Object> poolConfig = new GenericObjectPoolConfig<>();
        poolConfig.setMaxTotal(16);
        poolConfig.setMaxIdle(8);
        poolConfig.setMinIdle(4);
        
        // Lettuce client configuration
        LettucePoolingClientConfiguration clientConfig = 
            LettucePoolingClientConfiguration.builder()
                .poolConfig(poolConfig)
                .commandTimeout(Duration.ofSeconds(2))
                .build();
        
        LettuceConnectionFactory factory = 
            new LettuceConnectionFactory(sentinelConfig, clientConfig);
        
        factory.setValidateConnection(true);
        
        return factory;
    }
    
    @Bean
    public RedisTemplate<String, Object> redisTemplate(
            LettuceConnectionFactory connectionFactory) {
        
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);
        
        // Serializers
        template.setKeySerializer(new StringRedisSerializer());
        template.setValueSerializer(new GenericJackson2JsonRedisSerializer());
        template.setHashKeySerializer(new StringRedisSerializer());
        template.setHashValueSerializer(new GenericJackson2JsonRedisSerializer());
        
        template.afterPropertiesSet();
        
        return template;
    }
}
```

```java
@Service
@Slf4j
public class RedisBackupService {
    
    @Value("${redis.backup.directory}")
    private String backupDirectory;
    
    @Value("${redis.backup.retention.days}")
    private int retentionDays;
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    public RedisBackupService(RedisTemplate<String, Object> redisTemplate) {
        this.redisTemplate = redisTemplate;
    }
    
    /**
     * Perform backup (trigger RDB save and copy file)
     */
    @Scheduled(cron = "${redis.backup.schedule:0 0 2 * * *}")  // 2 AM daily
    public void performBackup() {
        log.info("Starting Redis backup");
        
        try {
            // Trigger RDB save
            redisTemplate.getConnectionFactory()
                .getConnection()
                .bgSave();
            
            // Wait for save to complete
            waitForSaveCompletion();
            
            // Copy RDB file to backup location
            copyRdbFile();
            
            // Cleanup old backups
            cleanupOldBackups();
            
            log.info("Redis backup completed successfully");
            
        } catch (Exception e) {
            log.error("Redis backup failed", e);
            // Send alert
            sendBackupFailureAlert(e);
        }
    }
    
    private void waitForSaveCompletion() throws InterruptedException {
        int maxWait = 300;  // 5 minutes
        int waited = 0;
        
        while (waited < maxWait) {
            Properties info = redisTemplate.getConnectionFactory()
                .getConnection()
                .info("persistence");
            
            String status = info.getProperty("rdb_bgsave_in_progress", "0");
            
            if ("0".equals(status)) {
                log.info("RDB save completed");
                return;
            }
            
            Thread.sleep(1000);
            waited++;
        }
        
        throw new RuntimeException("RDB save timeout");
    }
    
    private void copyRdbFile() throws IOException {
        String timestamp = LocalDateTime.now()
            .format(DateTimeFormatter.ofPattern("yyyyMMdd-HHmmss"));
        
        String backupFileName = String.format("dump-%s.rdb", timestamp);
        Path backupPath = Paths.get(backupDirectory, backupFileName);
        
        // Copy RDB file from Redis data directory to backup directory
        // This assumes access to Redis data directory
        Path sourceFile = Paths.get("/var/lib/redis/dump.rdb");
        
        if (Files.exists(sourceFile)) {
            Files.copy(sourceFile, backupPath, StandardCopyOption.REPLACE_EXISTING);
            
            // Compress backup
            compressBackup(backupPath);
            
            log.info("Backup file created: {}", backupPath);
        } else {
            log.warn("Source RDB file not found: {}", sourceFile);
        }
    }
    
    private void compressBackup(Path backupFile) throws IOException {
        Path gzipFile = Paths.get(backupFile.toString() + ".gz");
        
        try (FileInputStream fis = new FileInputStream(backupFile.toFile());
             FileOutputStream fos = new FileOutputStream(gzipFile.toFile());
             GZIPOutputStream gzos = new GZIPOutputStream(fos)) {
            
            byte[] buffer = new byte[1024];
            int len;
            while ((len = fis.read(buffer)) > 0) {
                gzos.write(buffer, 0, len);
            }
        }
        
        // Delete uncompressed file
        Files.delete(backupFile);
        
        log.info("Backup compressed: {}", gzipFile);
    }
    
    private void cleanupOldBackups() throws IOException {
        LocalDateTime cutoff = LocalDateTime.now().minusDays(retentionDays);
        
        Files.list(Paths.get(backupDirectory))
            .filter(path -> path.toString().endsWith(".rdb.gz"))
            .filter(path -> {
                try {
                    BasicFileAttributes attrs = Files.readAttributes(
                        path, 
                        BasicFileAttributes.class
                    );
                    
                    LocalDateTime fileTime = LocalDateTime.ofInstant(
                        attrs.creationTime().toInstant(),
                        ZoneId.systemDefault()
                    );
                    
                    return fileTime.isBefore(cutoff);
                    
                } catch (IOException e) {
                    return false;
                }
            })
            .forEach(path -> {
                try {
                    Files.delete(path);
                    log.info("Deleted old backup: {}", path);
                } catch (IOException e) {
                    log.error("Failed to delete old backup: {}", path, e);
                }
            });
    }
    
    private void sendBackupFailureAlert(Exception e) {
        // Send email, Slack notification, etc.
        log.error("ALERT: Redis backup failed!", e);
    }
}
```

```java
     * List available backups
     */
    public List<BackupFile> listBackups() throws IOException {
        return Files.list(Paths.get(backupDirectory))
            .filter(path -> path.toString().endsWith(".rdb.gz"))
            .map(path -> {
                try {
                    BasicFileAttributes attrs = Files.readAttributes(
                        path,
                        BasicFileAttributes.class
                    );
                    
                    return new BackupFile(
                        path.getFileName().toString(),
                        attrs.size(),
                        LocalDateTime.ofInstant(
                            attrs.creationTime().toInstant(),
                            ZoneId.systemDefault()
                        )
                    );
                    
                } catch (IOException e) {
                    return null;
                }
            })
            .filter(Objects::nonNull)
            .sorted(Comparator.comparing(BackupFile::getCreationTime).reversed())
            .collect(Collectors.toList());
    }
    
    /**
     * Restore from backup
     */
    public void restoreFromBackup(String backupFileName) throws IOException {
        log.warn("Starting Redis restore from backup: {}", backupFileName);
        
        Path backupFile = Paths.get(backupDirectory, backupFileName);
        
        if (!Files.exists(backupFile)) {
            throw new FileNotFoundException("Backup file not found: " + backupFileName);
        }
        
        // 1. Stop accepting writes (optional - requires BGSAVE)
        log.info("Preparing for restore...");
        
        // 2. Decompress backup
        Path tempRdbFile = decompressBackup(backupFile);
        
        // 3. Copy to Redis data directory
        Path targetFile = Paths.get(redisDataDirectory, "dump.rdb");
        Files.copy(tempRdbFile, targetFile, StandardCopyOption.REPLACE_EXISTING);
        
        // 4. Clean up temp file
        Files.delete(tempRdbFile);
        
        log.info("Restore completed. Redis restart required to load data.");
        log.warn("Action required: Restart Redis server to complete restore");
    }
    
    private Path decompressBackup(Path gzipFile) throws IOException {
        String tempFileName = "temp-" + System.currentTimeMillis() + ".rdb";
        Path tempFile = Paths.get(backupDirectory, tempFileName);
        
        try (FileInputStream fis = new FileInputStream(gzipFile.toFile());
             GZIPInputStream gzis = new GZIPInputStream(fis);
             FileOutputStream fos = new FileOutputStream(tempFile.toFile())) {
            
            byte[] buffer = new byte[1024];
            int len;
            while ((len = gzis.read(buffer)) > 0) {
                fos.write(buffer, 0, len);
            }
        }
        
        return tempFile;
    }
}
```

## Interview Questions

**Q1: What's the difference between RDB and AOF persistence?**

RDB (snapshots): Point-in-time binary snapshot, smaller files, faster restart, higher data loss risk (last save to crash), periodic saves. AOF (append-only file): Logs every write operation, larger files, slower restart, minimal data loss (1 sec with everysec fsync), continuous writes. Use RDB for: faster restarts, periodic backups, cache scenarios. Use AOF for: maximum durability, minimal data loss, transactional data. Recommendation: Use BOTH in production - RDB for fast restarts, AOF for durability.

**Q2: How does Redis Sentinel provide high availability?**

Sentinel monitors master and replicas. When master fails: (1) Sentinels detect failure (down-after-milliseconds), (2) Quorum of sentinels agree on failure (minimum 2 out of 3), (3) Sentinel initiates failover - promotes replica to master, (4) Other replicas reconfigured to replicate from new master, (5) Clients redirected to new master. Requires 3+ sentinels (odd number) for quorum. Automatic failover with no manual intervention. Provides monitoring, notification, and configuration provider for clients.

**Q3: When should you use Redis Cluster vs Sentinel?**

Sentinel: Single-master HA, automatic failover, dataset fits in memory of single instance, simpler setup. Use for: <100GB dataset, high availability without sharding. Cluster: Horizontal scaling, automatic sharding (16,384 hash slots), distributed writes, 3+ master nodes. Use for: >100GB dataset, high write throughput, need horizontal scaling. Cannot use both together. Cluster has built-in HA (replicas per shard). Choose based on: data size and scalability needs vs setup complexity.

**Q4: How do you implement disaster recovery for Redis?**

Multi-layered approach: (1) Replication - 1 master + 2+ replicas for HA. (2) Automated backups - daily RDB snapshots to S3/backup storage with retention policy. (3) Sentinel - automatic failover if master fails. (4) Cross-region replication - secondary region for regional failures. (5) Testing - regular restore tests and failover drills. (6) Monitoring - replication lag, persistence errors, disk space. (7) Runbook - documented procedures for different failure scenarios. Recovery RTO: <5 min with Sentinel, <30 min from backup.

**Q5: What are the best practices for Redis persistence configuration?**

Production configuration: (1) Enable both RDB + AOF - `appendonly yes` + `save 900 1` etc. (2) AOF fsync everysec - balance durability/performance. (3) Use AOF with RDB preamble (`aof-use-rdb-preamble yes`) - faster loading. (4) Configure auto AOF rewrite - prevent file growth. (5) Monitor disk space - persistence files need space. (6) Enable checksums - `rdbchecksum yes`. (7) Set stop-writes-on-bgsave-error - prevent data loss. (8) Regular backups - copy RDB files offsite. (9) Test restore - verify backups work.

**Key Takeaway**: Production Redis requires multi-layered approach: persistence (RDB + AOF), replication (master + replicas), high availability (Sentinel for failover OR Cluster for scaling), automated backups (daily with retention), and disaster recovery planning. Configure both RDB and AOF - RDB for faster restarts and backups, AOF for minimal data loss. Use Sentinel with 3+ instances for automatic failover. Enable replication with minimum 2 replicas. Automate backups to offsite storage. Monitor replication lag, persistence errors, and disk space. Test failover and restore procedures regularly. This ensures 99.99% uptime and zero data loss tolerance.
