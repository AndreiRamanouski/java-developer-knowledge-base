# Redis as a Cache

## Overview

Redis is an excellent choice for application-level caching due to its in-memory performance, rich data structures, and built-in expiration. Spring Boot provides declarative caching with annotations and flexible cache management through RedisCacheManager. Proper cache configuration dramatically improves application performance while reducing database load.

**Key Concept**: Use @Cacheable for read-through caching, @CachePut for write-through updates, and @CacheEvict for invalidation. Configure appropriate TTLs to balance freshness with performance. Implement cache-aside pattern for most use cases. Handle cache stampede with locking or probabilistic early expiration for high-traffic scenarios.

### @Cacheable - Read-Through Caching

**Basic Usage:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class UserService {
    
    private final UserRepository userRepository;
    
    /**
     * Cache user by ID
     * First call: fetches from database and caches
     * Subsequent calls: returns from cache
     */
    @Cacheable(value = "users", key = "#id")
    public User getUserById(Long id) {
        log.info("Fetching user {} from database", id);
        return userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
    }
    
    /**
     * Cache with String key
     */
    @Cacheable(value = "users", key = "#username")
    public User getUserByUsername(String username) {
        log.info("Fetching user '{}' from database", username);
        return userRepository.findByUsername(username)
            .orElseThrow(() -> new UserNotFoundException(username));
    }
    
    /**
     * Cache with composite key
     */
    @Cacheable(value = "users", key = "#firstName + '_' + #lastName")
    public List<User> getUsersByName(String firstName, String lastName) {
        log.info("Fetching users with name {} {}", firstName, lastName);
        return userRepository.findByFirstNameAndLastName(firstName, lastName);
    }
    
    /**
     * Conditional caching - only cache active users
     */
    @Cacheable(
        value = "users",
        key = "#id",
        condition = "#result != null && #result.status == 'ACTIVE'"
    )
    public User getActiveUserById(Long id) {
        return userRepository.findById(id).orElse(null);
    }
    
    /**
     * Unless condition - cache unless null
     */
    @Cacheable(
        value = "users",
        key = "#id",
        unless = "#result == null"
    )
    public User getUserOrNull(Long id) {
        return userRepository.findById(id).orElse(null);
    }
    
    /**
     * Multiple cache names
     */
    @Cacheable(value = {"users", "userCache"}, key = "#id")
    public User getUserWithMultipleCaches(Long id) {
        return userRepository.findById(id).orElseThrow();
    }
    
    /**
     * Cache entire list
     */
    @Cacheable(value = "userLists", key = "'all'")
    public List<User> getAllUsers() {
        log.info("Fetching all users from database");
        return userRepository.findAll();
    }
    
    /**
     * Cache with method name in key
     */
    @Cacheable(value = "users", key = "#root.methodName + '_' + #id")
    public User getUserWithMethodName(Long id) {
        return userRepository.findById(id).orElseThrow();
    }
}
```

### @CachePut - Write-Through Caching

**Update Cache:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class UserService {
    
    private final UserRepository userRepository;
    
    /**
     * Update cache after creating user
     * Always executes method and updates cache
     */
    @CachePut(value = "users", key = "#result.id")
    public User createUser(User user) {
        log.info("Creating user: {}", user.getUsername());
        User savedUser = userRepository.save(user);
        log.info("User created and cached: {}", savedUser.getId());
        return savedUser;
    }
    
    /**
     * Update cache after updating user
     */
    @CachePut(value = "users", key = "#id")
    public User updateUser(Long id, UserUpdateRequest request) {
        log.info("Updating user: {}", id);
        
        User user = userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
        
        user.setFirstName(request.getFirstName());
        user.setLastName(request.getLastName());
        user.setEmail(request.getEmail());
        
        User updatedUser = userRepository.save(user);
        log.info("User updated and cache refreshed: {}", id);
        
        return updatedUser;
    }
    
    /**
     * Update multiple caches
     */
    @CachePut(value = {"users", "userCache"}, key = "#result.id")
    public User updateUserInMultipleCaches(User user) {
        return userRepository.save(user);
    }
    
    /**
     * Conditional cache update
     */
    @CachePut(
        value = "users",
        key = "#result.id",
        condition = "#result.status == 'ACTIVE'"
    )
    public User activateUser(Long id) {
        User user = userRepository.findById(id).orElseThrow();
        user.setStatus("ACTIVE");
        return userRepository.save(user);
    }
}
```

### @CacheEvict - Cache Invalidation

**Evict Cache:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class UserService {
    
    private final UserRepository userRepository;
    
    /**
     * Evict single cache entry
     */
    @CacheEvict(value = "users", key = "#id")
    public void deleteUser(Long id) {
        log.info("Deleting user: {}", id);
        userRepository.deleteById(id);
        log.info("User deleted and cache evicted: {}", id);
    }
    
    /**
     * Evict all cache entries
     */
    @CacheEvict(value = "users", allEntries = true)
    public void deleteAllUsers() {
        log.info("Deleting all users");
        userRepository.deleteAll();
        log.info("All users deleted and cache cleared");
    }
    
    /**
     * Evict multiple caches
     */
    @CacheEvict(value = {"users", "userCache", "userLists"}, key = "#id")
    public void removeUserFromAllCaches(Long id) {
        userRepository.deleteById(id);
    }
    
    /**
     * Evict before method execution (default is after)
     */
    @CacheEvict(
        value = "users",
        key = "#id",
        beforeInvocation = true
    )
    public void deleteUserBeforeEviction(Long id) {
        // Cache evicted before this executes
        // Useful if method might throw exception
        userRepository.deleteById(id);
    }
    
    /**
     * Conditional eviction
     */
    @CacheEvict(
        value = "users",
        key = "#id",
        condition = "#result == true"
    )
    public boolean deactivateUser(Long id) {
        try {
            User user = userRepository.findById(id).orElseThrow();
            user.setStatus("INACTIVE");
            userRepository.save(user);
            return true;
        } catch (Exception e) {
            return false;
        }
    }
    
    /**
     * Scheduled cache eviction
     */
    @CacheEvict(value = "userLists", allEntries = true)
    @Scheduled(fixedRate = 3600000)  // Every hour
    public void evictUserListsCache() {
        log.info("Evicting user lists cache (scheduled)");
    }
}
```

### @Caching - Combine Multiple Operations

**Complex Caching:**

```java
@Service
@RequiredArgsConstructor
public class UserService {

     * Update and evict different caches

        put = {
            @CachePut(value = "users", key = "#result.id")

            @CacheEvict(value = "userLists", allEntries = true),
            @CacheEvict(value = "userStats", allEntries = true)
        }

        return userRepository.save(user);

    /**
     * Multiple evictions with different keys
     */
    @Caching(
        evict = {
            @CacheEvict(value = "users", key = "#user.id"),
            @CacheEvict(value = "users", key = "#user.username"),
            @CacheEvict(value = "userLists", allEntries = true)
        }
    )
    public void deleteUserAndEvictAll(User user) {
        userRepository.delete(user);
    }
```

### Custom Cache Key Generator

**Key Generation:**

```java
@Component
public class CustomCacheKeyGenerator implements KeyGenerator {
    
    @Override
    public Object generate(Object target, Method method, Object... params) {
        // Custom key generation logic
        StringBuilder key = new StringBuilder();
        
        key.append(target.getClass().getSimpleName());
        key.append("_");
        key.append(method.getName());
        
        for (Object param : params) {
            key.append("_");
            if (param != null) {
                key.append(param.toString());
            }
        }
        
        return key.toString();
    }
}

@Component
public class UserIdKeyGenerator implements KeyGenerator {
    
    @Override
    public Object generate(Object target, Method method, Object... params) {
        // Generate key from User object's ID
        for (Object param : params) {
            if (param instanceof User) {
                return "user_" + ((User) param).getId();
            }
        }
        return "unknown";
    }
}

        return userRepository.findById(id).orElseThrow();

    @Cacheable(value = "users", keyGenerator = "userIdKeyGenerator")
    public User cacheByUserObject(User user) {
        return userRepository.findById(user.getId()).orElseThrow();
```

## 2. RedisCacheManager Configuration

### Basic RedisCacheManager Setup

**Configuration:**

```java
@Configuration
@EnableCaching
public class RedisCacheConfig {
    
    /**
     * Configure RedisCacheManager with default settings
     */
    @Bean
    public RedisCacheManager cacheManager(RedisConnectionFactory connectionFactory) {
        RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
            // Key serializer: String
            .serializeKeysWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new StringRedisSerializer()
                )
            )
            // Value serializer: JSON
            .serializeValuesWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new GenericJackson2JsonRedisSerializer()
                )
            )
            // Default TTL
            .entryTtl(Duration.ofMinutes(30))
            // Don't cache null values
            .disableCachingNullValues()
            // Cache key prefix
            .prefixCacheNameWith("myapp:");
        
        return RedisCacheManager.builder(connectionFactory)
            .cacheDefaults(config)
            .build();
    }
}
```

### Advanced RedisCacheManager Configuration

**Per-Cache Configuration:**

```java
@Configuration
@EnableCaching
public class AdvancedRedisCacheConfig {
    
    @Bean
    public RedisCacheManager cacheManager(
            RedisConnectionFactory connectionFactory,
            ObjectMapper objectMapper) {
        
        // Configure JSON serializer with custom ObjectMapper
        GenericJackson2JsonRedisSerializer jsonSerializer = 
            new GenericJackson2JsonRedisSerializer(objectMapper);
        
        // Default configuration (30 minutes)
        RedisCacheConfiguration defaultConfig = RedisCacheConfiguration
            .defaultCacheConfig()
            .serializeKeysWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new StringRedisSerializer()
                )
            )
            .serializeValuesWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    jsonSerializer
                )
            )
            .entryTtl(Duration.ofMinutes(30))
            .disableCachingNullValues();
        
        // Per-cache configurations
        Map<String, RedisCacheConfiguration> cacheConfigurations = new HashMap<>();
        
        // Users cache: 1 hour TTL
        cacheConfigurations.put("users", 
            defaultConfig.entryTtl(Duration.ofHours(1)));
        
        // Products cache: 15 minutes TTL
        cacheConfigurations.put("products",
            defaultConfig.entryTtl(Duration.ofMinutes(15)));
        
        // Session cache: 30 minutes TTL, allow null values
        cacheConfigurations.put("sessions",
            RedisCacheConfiguration.defaultCacheConfig()
                .serializeKeysWith(
                    RedisSerializationContext.SerializationPair.fromSerializer(
                        new StringRedisSerializer()
                    )
                )
                .serializeValuesWith(
                    RedisSerializationContext.SerializationPair.fromSerializer(
                        jsonSerializer
                    )
                )
                .entryTtl(Duration.ofMinutes(30))
                // Allow null values for sessions
        );
        
        // Config cache: 24 hours TTL
        cacheConfigurations.put("config",
            defaultConfig.entryTtl(Duration.ofHours(24)));
        
        // Stats cache: 5 minutes TTL
        cacheConfigurations.put("stats",
            defaultConfig.entryTtl(Duration.ofMinutes(5)));
        
        return RedisCacheManager.builder(connectionFactory)
            .cacheDefaults(defaultConfig)
            .withInitialCacheConfigurations(cacheConfigurations)
            .transactionAware()  // Enable transaction support
            .build();
    }
    
    /**
     * Custom ObjectMapper for cache serialization
     */
    @Bean
    public ObjectMapper cacheObjectMapper() {
        ObjectMapper mapper = new ObjectMapper();
        
        // Configure for optimal caching
        mapper.disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);
        mapper.registerModule(new JavaTimeModule());
        mapper.setVisibility(PropertyAccessor.ALL, JsonAutoDetect.Visibility.ANY);
        mapper.activateDefaultTyping(
            mapper.getPolymorphicTypeValidator(),
            ObjectMapper.DefaultTyping.NON_FINAL,
            JsonTypeInfo.As.PROPERTY
        );
        
        return mapper;
    }
}
```

**Runtime Cache Configuration:**

```java
@Configuration

@Service
@RequiredArgsConstructor
public class DynamicCacheService {
    
    private final CacheManager cacheManager;
    
    /**
     * Create cache dynamically at runtime
     */
    public void createCache(String cacheName, Duration ttl) {
        // Get or create cache
        Cache cache = cacheManager.getCache(cacheName);
        
        if (cache == null) {
            // Cache will be created on first access
            // with default configuration
            log.info("Cache {} will be created on first access", cacheName);
        }
    }
    
    /**
     * Manually put value in cache
     */
    public void putInCache(String cacheName, String key, Object value) {
        Cache cache = cacheManager.getCache(cacheName);
        
        if (cache != null) {
            cache.put(key, value);
        }
    }
    
    /**
     * Get value from cache
     */
    public Object getFromCache(String cacheName, String key) {
        Cache cache = cacheManager.getCache(cacheName);
        
        if (cache != null) {
            Cache.ValueWrapper wrapper = cache.get(key);
            return wrapper != null ? wrapper.get() : null;
        }
        
        return null;
    }
    
    /**
     * Clear specific cache
     */
    public void clearCache(String cacheName) {
        Cache cache = cacheManager.getCache(cacheName);
        
        if (cache != null) {
            cache.clear();
            log.info("Cleared cache: {}", cacheName);
        }
    }
    
    /**
     * Clear all caches
     */
    public void clearAllCaches() {
        cacheManager.getCacheNames()
            .forEach(cacheName -> {
                Cache cache = cacheManager.getCache(cacheName);
                if (cache != null) {
                    cache.clear();
                }
            });
        
        log.info("Cleared all caches");
    }
}
```

### Per-Cache TTL Configuration

**Different TTLs per Cache:**

```java
@Configuration
@EnableCaching
public class TtlCacheConfig {
    
    @Bean
    public RedisCacheManager cacheManager(RedisConnectionFactory connectionFactory) {
        
        Map<String, RedisCacheConfiguration> cacheConfigurations = new HashMap<>();
        
        // User data: Cache for 1 hour
        cacheConfigurations.put("users",
            createCacheConfig(Duration.ofHours(1)));
        
        // Product catalog: Cache for 15 minutes (changes frequently)
        cacheConfigurations.put("products",
            createCacheConfig(Duration.ofMinutes(15)));
        
        // Configuration: Cache for 24 hours (rarely changes)
        cacheConfigurations.put("config",
            createCacheConfig(Duration.ofHours(24)));
        
        // Search results: Cache for 5 minutes (volatile)
        cacheConfigurations.put("searchResults",
            createCacheConfig(Duration.ofMinutes(5)));
        
        // Session data: Cache for 30 minutes
        cacheConfigurations.put("sessions",
            createCacheConfig(Duration.ofMinutes(30)));
        
        // Statistics: Cache for 1 minute (real-time)
        cacheConfigurations.put("stats",
            createCacheConfig(Duration.ofMinutes(1)));
        
        return RedisCacheManager.builder(connectionFactory)
            .cacheDefaults(createCacheConfig(Duration.ofMinutes(30)))
            .withInitialCacheConfigurations(cacheConfigurations)
            .build();
    }
    
    private RedisCacheConfiguration createCacheConfig(Duration ttl) {
        return RedisCacheConfiguration.defaultCacheConfig()
            .serializeKeysWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new StringRedisSerializer()
                )
            )
            .serializeValuesWith(
                RedisSerializationContext.SerializationPair.fromSerializer(
                    new GenericJackson2JsonRedisSerializer()
                )
            )
            .entryTtl(ttl)
            .disableCachingNullValues();
    }
}
```

### Dynamic TTL Based on Data

**Conditional TTL:**

```java
@Service
@RequiredArgsConstructor
public class DynamicTtlService {
    
    private final RedisTemplate<String, Object> redisTemplate;
    
    /**
     * Set TTL based on data characteristics
     */
    public void cacheWithDynamicTtl(String key, Object value) {
        Duration ttl = calculateTtl(value);
        
        redisTemplate.opsForValue().set(key, value, ttl);
    }
    
    private Duration calculateTtl(Object value) {
        if (value instanceof User) {
            User user = (User) value;
            
            // Premium users: longer cache
            if ("PREMIUM".equals(user.getSubscription())) {
                return Duration.ofHours(2);
            }
            
            // Active users: medium cache
            if ("ACTIVE".equals(user.getStatus())) {
                return Duration.ofHours(1);
            }
            
            // Others: short cache
            return Duration.ofMinutes(15);
        }
        
        // Default TTL
        return Duration.ofMinutes(30);
    }
    
    /**
     * Refresh TTL without updating value
     */
    public void refreshTtl(String key, Duration ttl) {
        redisTemplate.expire(key, ttl);
    }
    
    /**
     * Get remaining TTL
     */
    public long getRemainingTtl(String key) {
        Long ttl = redisTemplate.getExpire(key, TimeUnit.SECONDS);
        return ttl != null ? ttl : -1;
    }
}
```

```java
/**
 * Hash-based key generator for complex objects
 */
@Component("hashKeyGenerator")
public class HashKeyGenerator implements KeyGenerator {
    
    @Override
    public Object generate(Object target, Method method, Object... params) {
        StringBuilder key = new StringBuilder();
        
        key.append(target.getClass().getSimpleName());
        key.append("_");
        key.append(method.getName());
        
        for (Object param : params) {
            key.append("_");
            if (param != null) {
                key.append(param.hashCode());
            }
        }
        
        return key.toString();
    }
}

/**
 * JSON-based key generator
 */
@Component("jsonKeyGenerator")
@RequiredArgsConstructor
public class JsonKeyGenerator implements KeyGenerator {
    
    private final ObjectMapper objectMapper;
    
    @Override
    public Object generate(Object target, Method method, Object... params) {
        try {
            StringBuilder key = new StringBuilder();
            
            key.append(method.getName());
            key.append("_");
            
            for (Object param : params) {
                if (param != null) {
                    String json = objectMapper.writeValueAsString(param);
                    key.append(DigestUtils.md5DigestAsHex(json.getBytes()));
                }
            }
            
            return key.toString();
            
        } catch (JsonProcessingException e) {
            throw new IllegalStateException("Failed to generate cache key", e);
        }
    }
}

/**
 * Tenant-aware key generator (multi-tenancy)

@Component("tenantKeyGenerator")
public class TenantKeyGenerator implements KeyGenerator {

        for (Object param : params) {
            key.append("_");
            if (param != null) {
                key.append(param.toString());
            }
        }
        
        return key.toString();
    }
}
```

## 5. Cache Patterns

### Cache-Aside Pattern (Lazy Loading)

**Most Common Pattern:**

```java
/**
 * Cache-Aside (Lazy Loading) Pattern
 * 
 * Flow:
 * 1. Application checks cache
 * 2. If cache miss, fetch from database
 * 3. Store in cache for next request
 * 4. Return data
 * 
 * Pros: Only cache what's needed, lazy loading
 * Cons: Cache miss penalty, possible stale data
 */

@Service
@RequiredArgsConstructor
@Slf4j
public class CacheAsideService {
    
    private final UserRepository userRepository;
    private final RedisTemplate<String, Object> redisTemplate;

     * Manual cache-aside implementation
     */
    public User getUserManual(Long id) {

        User user = (User) redisTemplate.opsForValue().get(key);

        user = userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
        
        // 3. Store in cache
        redisTemplate.opsForValue().set(key, user, Duration.ofMinutes(30));
        
        return user;
    }
    
    /**
     * Declarative cache-aside with @Cacheable
     * Spring automatically implements cache-aside
     */
    @Cacheable(value = "users", key = "#id")
    public User getUserDeclarative(Long id) {
        // Spring handles:
        // 1. Check cache
        // 2. If miss, execute method
        // 3. Cache result
        // 4. Return result
        
        log.info("Fetching user from database: {}", id);
        return userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
    }
    
    /**
     * Update with cache-aside
     */
    public User updateUser(Long id, UserUpdateRequest request) {
        String key = "user:" + id;
        
        // Update database
        User user = userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
        
        user.setFirstName(request.getFirstName());
        user.setLastName(request.getLastName());
        
        User updatedUser = userRepository.save(user);
        
        // Invalidate cache (let next read repopulate)
        redisTemplate.delete(key);
        
        return updatedUser;
    }
```

### Write-Behind Pattern (Write-Back)

**Asynchronous Cache Updates:**

```java
/**
 * Write-Behind (Write-Back) Pattern
 * 
 * Writes go to cache immediately
 * Database updated asynchronously later
 * 
 * Pros: Low write latency, batching possible
 * Cons: Possible data loss, complexity
 */

@Service
@RequiredArgsConstructor
@Slf4j
public class WriteBehindService {
    
    private final UserRepository userRepository;
    private final RedisTemplate<String, Object> redisTemplate;
    private final Queue<WriteOperation> writeQueue = new ConcurrentLinkedQueue<>();
    
    /**
     * Write to cache immediately
     */
    public User createUserWriteBehind(User user) {
        // Write to cache immediately
        String key = "user:" + user.getId();
        redisTemplate.opsForValue().set(key, user, Duration.ofMinutes(30));
        
        // Queue for async database write
        writeQueue.offer(new WriteOperation(WriteType.CREATE, user));
        
        return user;
    }
    
    /**
     * Async database writer
     */
    @Scheduled(fixedDelay = 5000)  // Every 5 seconds
    public void processPendingWrites() {
        List<WriteOperation> batch = new ArrayList<>();
        
        WriteOperation op;
        while ((op = writeQueue.poll()) != null) {
            batch.add(op);
            
            if (batch.size() >= 100) {  // Batch size limit
                break;
            }
        }
        
        if (!batch.isEmpty()) {
            log.info("Processing {} pending writes", batch.size());
            
            batch.forEach(operation -> {
                try {
                    if (operation.getType() == WriteType.CREATE) {
                        userRepository.save((User) operation.getData());
                    } else if (operation.getType() == WriteType.UPDATE) {
                        userRepository.save((User) operation.getData());
                    } else if (operation.getType() == WriteType.DELETE) {
                        userRepository.deleteById((Long) operation.getData());
                    }
                } catch (Exception e) {
                    log.error("Failed to write to database", e);
                    // Could re-queue or handle error
                }
            });
        }
    }
}

@Data
@AllArgsConstructor
class WriteOperation {
    private WriteType type;
    private Object data;
}

enum WriteType {
    CREATE, UPDATE, DELETE
}
```

```java
@Service

        user = userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
        
        redisTemplate.opsForValue().set(key, user, Duration.ofMinutes(30));
        
        return user;
    }

    protected void refreshAsync(Long id, String key) {
        try {
            log.info("Refreshing cache for user: {}", id);
            
            User user = userRepository.findById(id)
                .orElseThrow(() -> new UserNotFoundException(id));
            
            redisTemplate.opsForValue().set(key, user, Duration.ofMinutes(30));
            
        } catch (Exception e) {
            log.error("Failed to refresh cache for user: {}", id, e);
        }
    }
}
```

## 6. Handling Cache Stampede

### Understanding Cache Stampede

**Problem:**

```
Cache Stampede (Thundering Herd):

Scenario:
1. Popular cache entry expires
2. Multiple requests hit at same time
3. All requests miss cache simultaneously
4. All requests query database concurrently
5. Database overloaded, performance degraded

Example:
- Homepage cache expires
- 1000 concurrent users request homepage
- All 1000 requests query database
- Database overwhelmed
```

### Solution 1: Distributed Locking

**Lock-Based Prevention:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class CacheStampedeLockService {
    
    private final UserRepository userRepository;
    private final RedisTemplate<String, Object> redisTemplate;
    private final StringRedisTemplate stringRedisTemplate;
    
    /**
     * Prevent stampede with distributed lock
     */
    public User getUserWithLock(Long id) {
        String cacheKey = "user:" + id;
        String lockKey = "lock:user:" + id;
        
        // Try cache first
        User user = (User) redisTemplate.opsForValue().get(cacheKey);
        if (user != null) {
            return user;
        }
        
        // Cache miss - try to acquire lock
        String lockValue = UUID.randomUUID().toString();
        Boolean lockAcquired = stringRedisTemplate.opsForValue()
            .setIfAbsent(lockKey, lockValue, Duration.ofSeconds(10));
        
        if (Boolean.TRUE.equals(lockAcquired)) {
            try {
                // Double-check cache (might be populated while waiting)
                user = (User) redisTemplate.opsForValue().get(cacheKey);
                if (user != null) {
                    return user;
                }
                
                // Load from database
                log.info("Loading user {} from database (lock holder)", id);
                user = userRepository.findById(id)
                    .orElseThrow(() -> new UserNotFoundException(id));
                
                // Cache the result
                redisTemplate.opsForValue().set(cacheKey, user, Duration.ofMinutes(30));
                
                return user;
                
            } finally {
                // Release lock
                releaseLock(lockKey, lockValue);
            }
            
        } else {
            // Lock held by another thread - wait and retry
            return waitAndRetry(id, cacheKey, 5);
        }
    }
    
    private void releaseLock(String lockKey, String lockValue) {
        String currentValue = stringRedisTemplate.opsForValue().get(lockKey);
        if (lockValue.equals(currentValue)) {
            stringRedisTemplate.delete(lockKey);
        }
    }
    
    private User waitAndRetry(Long id, String cacheKey, int maxRetries) {
        for (int i = 0; i < maxRetries; i++) {
            try {
                Thread.sleep(100);  // Wait 100ms
                
                // Check if cache populated
                User user = (User) redisTemplate.opsForValue().get(cacheKey);
                if (user != null) {
                    log.info("User {} found in cache after waiting", id);
                    return user;
                }
                
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            }
        }
        
        // Fallback: load from database
        log.warn("Loading user {} from database after max retries", id);
        return userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
    }
}
```

### Solution 2: Probabilistic Early Expiration

**XFetch Algorithm:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class ProbabilisticExpirationService {
    
    private final UserRepository userRepository;
    private final RedisTemplate<String, Object> redisTemplate;
    private final Random random = new Random();
    
    /**
     * Probabilistic early expiration (XFetch)
     * 
     * Probability of refresh = delta * beta * log(random)
     * where delta = time since stored
     *       beta = recomputation time factor
     */
    public User getUserWithProbabilisticRefresh(Long id) {
        String cacheKey = "user:" + id;
        String metaKey = "user:meta:" + id;
        
        // Get cached user
        User user = (User) redisTemplate.opsForValue().get(cacheKey);
        
        if (user != null) {
            // Get cache metadata
            CacheMeta meta = (CacheMeta) redisTemplate.opsForValue().get(metaKey);
            
            if (meta != null && shouldRefreshEarly(meta)) {
                // Refresh asynchronously
                log.info("Triggering early refresh for user: {}", id);
                refreshAsync(id);
            }
            
            return user;
        }
        
        // Cache miss - load and cache
        return loadAndCache(id);
    }
    
    private boolean shouldRefreshEarly(CacheMeta meta) {
        long now = System.currentTimeMillis();
        long delta = now - meta.getStoredAt();
        long ttl = meta.getTtl();
        
        // XFetch algorithm
        double beta = 1.0;  // Recomputation time factor
        double threshold = delta * beta * Math.log(random.nextDouble());
        
        return threshold > ttl;
    }
    
    private User loadAndCache(Long id) {
        User user = userRepository.findById(id)
            .orElseThrow(() -> new UserNotFoundException(id));
        
        long ttl = Duration.ofMinutes(30).toMillis();
        
        // Cache user
        redisTemplate.opsForValue().set(
            "user:" + id,
            user,
            Duration.ofMinutes(30)
        );
        
        // Cache metadata
        CacheMeta meta = new CacheMeta(System.currentTimeMillis(), ttl);
        redisTemplate.opsForValue().set(
            "user:meta:" + id,
            meta,
            Duration.ofMinutes(30)
        );
        
        return user;
    }
    
    @Async
    protected void refreshAsync(Long id) {
        loadAndCache(id);
    }
}

@Data
@AllArgsConstructor
class CacheMeta implements Serializable {
    private long storedAt;
    private long ttl;
}
```

### Solution 4: Request Coalescing

**Deduplicate Concurrent Requests:**

```java
@Service
@Slf4j
public class RequestCoalescingService {
    
    @Autowired
    private UserRepository userRepository;
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    // Track in-flight requests
    private final ConcurrentHashMap<Long, CompletableFuture<User>> inFlightRequests = 
        new ConcurrentHashMap<>();
    
    /**
     * Coalesce concurrent requests for same user
     */
    public CompletableFuture<User> getUserAsync(Long id) {
        String cacheKey = "user:" + id;
        
        // Check cache
        User cachedUser = (User) redisTemplate.opsForValue().get(cacheKey);
        if (cachedUser != null) {
            return CompletableFuture.completedFuture(cachedUser);
        }
        
        // Check if request already in flight
        return inFlightRequests.computeIfAbsent(id, userId -> 
            CompletableFuture.supplyAsync(() -> {
                try {
                    // Double-check cache
                    User user = (User) redisTemplate.opsForValue().get(cacheKey);
                    if (user != null) {
                        return user;
                    }
                    
                    // Load from database
                    log.info("Loading user {} from database", userId);
                    user = userRepository.findById(userId)
                        .orElseThrow(() -> new UserNotFoundException(userId));
                    
                    // Cache result
                    redisTemplate.opsForValue().set(
                        cacheKey,
                        user,
                        Duration.ofMinutes(30)
                    );
                    
                    return user;
                    
                } finally {
                    // Remove from in-flight map
                    inFlightRequests.remove(userId);
                }
            })
        );
    }
}
```

## Best Practices Summary

### ✅ DO:

1. **Use @Cacheable** for read operations (cache-aside)
2. **Use @CachePut** for updates (write-through)
3. **Use @CacheEvict** for deletions
4. **Configure appropriate TTLs** per cache type
5. **Use JSON serialization** for values
6. **Implement cache stampede** prevention
7. **Monitor cache hit ratios**
8. **Use cache warming** for popular data
9. **Set null value policy** appropriately
10. **Test cache behavior** thoroughly

### ❌ DON'T:

1. **Don't cache everything** - only frequently accessed data
2. **Don't use infinite TTLs** - risk stale data
3. **Don't cache highly volatile** data
4. **Don't ignore cache size** - monitor memory usage
5. **Don't cache large objects** without consideration
6. **Don't forget to evict** on updates/deletes
7. **Don't use default serialization** (JDK)
8. **Don't cache null values** without reason
9. **Don't ignore cache warming** for critical data
10. **Don't skip monitoring** - measure effectiveness

## Interview Questions

**Q1: Explain the difference between @Cacheable, @CachePut, and @CacheEvict.**

@Cacheable: Read-through caching - checks cache first, executes method on miss, caches result. @CachePut: Write-through - always executes method, updates cache with result. @CacheEvict: Invalidation - removes entries from cache, can be single key or allEntries=true. Use @Cacheable for reads, @CachePut for updates, @CacheEvict for deletes. Can combine with @Caching for complex scenarios.

**Q2: What is cache stampede and how do you prevent it?**

Cache stampede (thundering herd): Popular cache expires, many concurrent requests miss cache simultaneously, all query database, overwhelming it. Solutions: (1) Distributed locking - first request gets lock, loads data, others wait. (2) Probabilistic early expiration - XFetch algorithm refreshes before expiration. (3) Background refresh - scheduled warming of popular items. (4) Request coalescing - deduplicate concurrent requests. Choose based on traffic patterns and requirements.

**Q3: What's the difference between cache-aside and cache-through patterns?**

Cache-aside (lazy loading): Application checks cache, on miss fetches from database and populates cache. Spring's @Cacheable implements this. Write-through: Writes go through cache to database synchronously (@CachePut). Write-behind: Writes to cache immediately, database updated asynchronously. Cache-aside most common - simple, only caches what's needed. Write-through for consistency. Write-behind for performance but complex.

**Q4: How do you configure different TTLs for different cache types?**

Configure per-cache TTLs in RedisCacheManager: `Map<String, RedisCacheConfiguration> configs; configs.put("users", createConfig(Duration.ofHours(1))); configs.put("products", createConfig(Duration.ofMinutes(15)));` Different data has different volatility: user profiles (hours), product catalog (minutes), configuration (days), stats (seconds). Consider update frequency and staleness tolerance.

**Q5: What are the best practices for cache key generation?**

Use SpEL for simple keys: `key = "#id"` or composite `key = "#firstName + '_' + #lastName"`. For complex objects, implement custom KeyGenerator with consistent hashing. Include tenant/user context for multi-tenancy. Keep keys short but unique. Consider including method name to avoid collisions. Hash collections consistently. For objects, use ID rather than hashCode (can change). Document key format for debugging.

- ✅ **TTL Configuration** - Global defaults, per-cache overrides, dynamic TTLs
- ✅ **Key Generation** - SpEL expressions, custom KeyGenerators
