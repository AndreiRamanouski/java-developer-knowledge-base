# Querying MongoDB in Spring

## Overview

Spring Data MongoDB provides multiple approaches for querying data, from simple method names to complex aggregation pipelines. Choose the right approach based on query complexity: derived query methods for simple queries, @Query for moderate complexity, Criteria API for dynamic queries, and Aggregation for complex analytics.

**Key Concept**: Start with derived query methods for readability, move to @Query for custom logic, use Criteria API for dynamic filtering, and leverage Aggregation framework for complex analytics and reporting. Each approach has its place in a well-designed application.

## 2. @Query Annotation with JSON Queries

### Basic @Query Usage

**MongoDB Query Syntax:**

```java
@Repository
public interface UserRepository extends MongoRepository<User, String> {
    
    // ====================
    // SIMPLE QUERIES
    // ====================
    
    @Query("{ 'email': ?0 }")
    User findByEmailQuery(String email);
    
    @Query("{ 'status': ?0 }")
    List<User> findByStatusQuery(String status);
    
    // ====================
    // MULTIPLE PARAMETERS
    // ====================
    
    @Query("{ 'status': ?0, 'age': { $gte: ?1 } }")
    List<User> findByStatusAndMinAge(String status, Integer minAge);
    
    @Query("{ 'city': ?0, 'country': ?1, 'status': ?2 }")
    List<User> findByCityCountryStatus(String city, String country, String status);
    
    // ====================
    // COMPLEX CONDITIONS
    // ====================
    
    @Query("{ 'age': { $gte: ?0, $lte: ?1 } }")
    List<User> findByAgeRange(Integer minAge, Integer maxAge);
    
    @Query("{ 'status': { $in: ?0 } }")
    List<User> findByStatuses(List<String> statuses);
    
    @Query("{ 'status': { $ne: ?0 } }")
    List<User> findByStatusNotEqual(String status);
    
    // ====================
    // REGEX QUERIES
    // ====================
    
    @Query("{ 'email': { $regex: ?0, $options: 'i' } }")
    List<User> findByEmailPattern(String pattern);
    
    @Query("{ 'firstName': { $regex: '^?0', $options: 'i' } }")
    List<User> findByFirstNameStartsWith(String prefix);
    
    // ====================
    // DATE QUERIES
    // ====================
    
    @Query("{ 'createdAt': { $gte: ?0, $lte: ?1 } }")
    List<User> findByCreatedAtBetween(LocalDateTime start, LocalDateTime end);
    
    @Query("{ 'lastLoginAt': { $gte: ?0 } }")
    List<User> findActiveUsersSince(LocalDateTime date);
    
    // ====================
    // NULL CHECKS
    // ====================
    
    @Query("{ 'lastLoginAt': { $exists: true, $ne: null } }")
    List<User> findUsersWithLogin();
    
    @Query("{ 'lastLoginAt': null }")
    List<User> findUsersNeverLoggedIn();
}
```

```java
@Service
@RequiredArgsConstructor
public class UserDynamicQueryService {

     * Simple criteria query
     */

        Query query = new Query();
```

### Dynamic Query Building

**Build Queries Based on Parameters:**

```java
@Service
@RequiredArgsConstructor
public class UserSearchService {
    
    private final MongoTemplate mongoTemplate;
    
    /**
     * Dynamic query with optional filters
     */
    public List<User> searchUsers(UserSearchCriteria searchCriteria) {
        Query query = new Query();
        List<Criteria> criteriaList = new ArrayList<>();
        
        // Add criteria only if provided
        if (searchCriteria.getStatus() != null) {
            criteriaList.add(Criteria.where("status").is(searchCriteria.getStatus()));
        }
        
        if (searchCriteria.getMinAge() != null) {
            criteriaList.add(Criteria.where("age").gte(searchCriteria.getMinAge()));
        }
        
        if (searchCriteria.getMaxAge() != null) {
            criteriaList.add(Criteria.where("age").lte(searchCriteria.getMaxAge()));
        }
        
        if (searchCriteria.getCity() != null) {
            criteriaList.add(Criteria.where("address.city").is(searchCriteria.getCity()));
        }
        
        if (searchCriteria.getCountry() != null) {
            criteriaList.add(Criteria.where("country").is(searchCriteria.getCountry()));
        }
        
        if (searchCriteria.getSearchTerm() != null) {
            String regex = searchCriteria.getSearchTerm();
            Criteria searchCriteria2 = new Criteria().orOperator(
                Criteria.where("firstName").regex(regex, "i"),
                Criteria.where("lastName").regex(regex, "i"),
                Criteria.where("email").regex(regex, "i")
            );
            criteriaList.add(searchCriteria2);
        }
        
        if (searchCriteria.getTags() != null && !searchCriteria.getTags().isEmpty()) {
            criteriaList.add(Criteria.where("tags").all(searchCriteria.getTags()));
        }
        
        if (searchCriteria.getCreatedAfter() != null) {
            criteriaList.add(Criteria.where("createdAt").gte(searchCriteria.getCreatedAfter()));
        }
        
        // Combine all criteria with AND
        if (!criteriaList.isEmpty()) {
            query.addCriteria(new Criteria().andOperator(
                criteriaList.toArray(new Criteria[0])
            ));
        }
        
        // Add sorting
        if (searchCriteria.getSortBy() != null) {
            Sort.Direction direction = searchCriteria.getSortOrder() == SortOrder.DESC 
                ? Sort.Direction.DESC 
                : Sort.Direction.ASC;
            
            query.with(Sort.by(direction, searchCriteria.getSortBy()));
        }
        
        // Add pagination
        if (searchCriteria.getPage() != null && searchCriteria.getPageSize() != null) {
            Pageable pageable = PageRequest.of(
                searchCriteria.getPage(), 
                searchCriteria.getPageSize()
            );
            query.with(pageable);
        }
        
        return mongoTemplate.find(query, User.class);
    }
}

@Data
public class UserSearchCriteria {
    private String status;
    private Integer minAge;
    private Integer maxAge;
    private String city;
    private String country;
    private String searchTerm;
    private List<String> tags;
    private LocalDateTime createdAfter;
    
    private String sortBy;
    private SortOrder sortOrder;
    private Integer page;
    private Integer pageSize;
}

enum SortOrder {
    ASC, DESC
}
```

```java
@Service

public class UserAdvancedQueryService {

    }

     * Complex nested logic
     * (status = 'ACTIVE' OR status = 'PENDING') AND age >= 18 AND country = 'USA'

            Criteria.where("status").is("ACTIVE"),
            Criteria.where("status").is("PENDING")
        );
        
        Criteria ageCriteria = Criteria.where("age").gte(18);
        Criteria countryCriteria = Criteria.where("country").is("USA");
        
        Criteria finalCriteria = new Criteria().andOperator(
            statusCriteria,
            ageCriteria,
            countryCriteria
        );
        
        Query query = new Query(finalCriteria);
        return mongoTemplate.find(query, User.class);
    }
}
```

```java
@Service
@RequiredArgsConstructor
public class UserUpdateService {
    
    private final MongoTemplate mongoTemplate;
    
    /**
     * Update single field
     */
    public UpdateResult updateUserStatus(String userId, String newStatus) {
        Query query = new Query(Criteria.where("_id").is(userId));
        Update update = new Update()
            .set("status", newStatus)
            .set("lastModified", LocalDateTime.now());
        
        return mongoTemplate.updateFirst(query, update, User.class);
    }
    
    /**
     * Update multiple fields
     */
    public UpdateResult updateUserInfo(String userId, String firstName, String lastName) {
        Query query = new Query(Criteria.where("_id").is(userId));
        Update update = new Update()
            .set("firstName", firstName)
            .set("lastName", lastName)
            .inc("version", 1)
            .set("lastModified", LocalDateTime.now());
        
        return mongoTemplate.updateFirst(query, update, User.class);
    }
    
    /**
     * Update all matching documents
     */
    public UpdateResult activateUsersByCity(String city) {
        Query query = new Query(Criteria.where("address.city").is(city));
        Update update = new Update().set("status", "ACTIVE");
        
        return mongoTemplate.updateMulti(query, update, User.class);
    }
    
    /**
     * Upsert - insert if not exists
     */
    public UpdateResult upsertUser(String email, User user) {
        Query query = new Query(Criteria.where("email").is(email));
        Update update = new Update()
            .set("firstName", user.getFirstName())
            .set("lastName", user.getLastName())
            .set("age", user.getAge())
            .set("lastModified", LocalDateTime.now())
            .setOnInsert("createdAt", LocalDateTime.now())
            .setOnInsert("status", "ACTIVE");
        
        return mongoTemplate.upsert(query, update, User.class);
    }
    
    /**
     * Array operations
     */
    public UpdateResult addTagToUser(String userId, String tag) {
        Query query = new Query(Criteria.where("_id").is(userId));
        Update update = new Update()
            .addToSet("tags", tag);  // Add if not exists
        
        return mongoTemplate.updateFirst(query, update, User.class);
    }
    
    public UpdateResult removeTagFromUser(String userId, String tag) {
        Query query = new Query(Criteria.where("_id").is(userId));
        Update update = new Update()
            .pull("tags", tag);
        
        return mongoTemplate.updateFirst(query, update, User.class);
    }
}
```

## 4. Aggregation Pipeline with Aggregation Class

### Basic Aggregation Operations

**Simple Aggregations:**

```java
@Service
@RequiredArgsConstructor
public class UserAggregationService {
    
    private final MongoTemplate mongoTemplate;
    
    /**
     * Count users by status
     */
    public List<StatusCount> countUsersByStatus() {
        Aggregation aggregation = Aggregation.newAggregation(
            Aggregation.group("status").count().as("count"),
            Aggregation.project("count").and("_id").as("status"),
            Aggregation.sort(Sort.Direction.DESC, "count")
        );
        
        AggregationResults<StatusCount> results = mongoTemplate.aggregate(
            aggregation, "users", StatusCount.class
        );
        
        return results.getMappedResults();
    }
    
    /**
     * Calculate average age by city
     */
    public List<CityAverageAge> averageAgeByCity() {
        Aggregation aggregation = Aggregation.newAggregation(
            Aggregation.group("address.city")
                .avg("age").as("averageAge")
                .count().as("userCount"),
            Aggregation.project("averageAge", "userCount")
                .and("_id").as("city"),
            Aggregation.match(Criteria.where("userCount").gte(5)),
            Aggregation.sort(Sort.Direction.DESC, "averageAge")
        );
        
        AggregationResults<CityAverageAge> results = mongoTemplate.aggregate(
            aggregation, "users", CityAverageAge.class
```

```java
@Service
@RequiredArgsConstructor
public class UserAnalyticsService {
    
    private final MongoTemplate mongoTemplate;
    
    /**
     * User demographics report
     */
    public List<DemographicReport> getDemographicReport() {
        Aggregation aggregation = Aggregation.newAggregation(
            // Stage 1: Match only active users
            Aggregation.match(Criteria.where("status").is("ACTIVE")),
            
            // Stage 2: Group by country and city
            Aggregation.group("country", "address.city")
                .count().as("userCount")
                .avg("age").as("averageAge")
                .min("age").as("minAge")
                .max("age").as("maxAge"),
            
            // Stage 3: Project fields
            Aggregation.project()
                .and("_id.country").as("country")
                .and("_id.address.city").as("city")
                .and("userCount").as("totalUsers")
                .and("averageAge").as("avgAge")
                .and("minAge").as("youngestAge")
                .and("maxAge").as("oldestAge"),
            
            // Stage 4: Sort by country and city
            Aggregation.sort(Sort.Direction.ASC, "country", "city"),
            
            // Stage 5: Skip and limit for pagination
            Aggregation.skip(0L),
            Aggregation.limit(100)
        );
        
        AggregationResults<DemographicReport> results = mongoTemplate.aggregate(
            aggregation, "users", DemographicReport.class
        );
        
        return results.getMappedResults();
    }
    
    /**
     * User activity statistics
     */
    public List<ActivityStats> getActivityStatistics() {
        Aggregation aggregation = Aggregation.newAggregation(
            // Match users with login activity
            Aggregation.match(Criteria.where("lastLoginAt").ne(null)),
            
            // Add computed fields
            Aggregation.project("status", "lastLoginAt")
                .and("lastLoginAt").extractDayOfWeek().as("dayOfWeek")
                .and("lastLoginAt").extractHour().as("hourOfDay"),
            
            // Group by day of week
            Aggregation.group("dayOfWeek")
                .count().as("loginCount")
                .avg("hourOfDay").as("averageHour"),
            
            // Sort by day
            Aggregation.sort(Sort.Direction.ASC, "_id")
        );
        
        AggregationResults<ActivityStats> results = mongoTemplate.aggregate(
            aggregation, "users", ActivityStats.class
        );
        
        return results.getMappedResults();
    }
    
    /**
     * Users by age group

    public List<AgeGroupCount> getUsersByAgeGroup() {

            // Match active users
```

```java
@Service
@RequiredArgsConstructor
public class RestaurantSearchService {
    
    private final MongoTemplate mongoTemplate;
    
    /**
     * Find nearest restaurants
     */
    public List<Restaurant> findNearestRestaurants(
            double longitude, double latitude, double maxDistanceKm) {
        
        Point location = new Point(longitude, latitude);
        Distance distance = new Distance(maxDistanceKm, Metrics.KILOMETERS);
        
        NearQuery nearQuery = NearQuery.near(location)
            .maxDistance(distance)
            .spherical(true);
        
        Query query = new Query();
        query.addCriteria(Criteria.where("location").nearSphere(location)
            .maxDistance(maxDistanceKm / 6371.0));  // Convert km to radians
        
        return mongoTemplate.find(query, Restaurant.class);
    }
    
    /**
     * Find restaurants with GeoNear aggregation
     */
    public List<RestaurantWithDistance> findNearbyWithDistance(
            double longitude, double latitude, double maxDistanceMeters) {
        
        GeoJsonPoint location = new GeoJsonPoint(longitude, latitude);
        
        NearQuery nearQuery = NearQuery.near(location)
            .maxDistance(new Distance(maxDistanceMeters, Metrics.METERS))
            .spherical(true)
            .num(20);  // Limit results
        
        GeoResults<Restaurant> results = mongoTemplate.geoNear(
            nearQuery, Restaurant.class
        );
        
        return results.getContent().stream()
            .map(result -> new RestaurantWithDistance(
                result.getContent(),
                result.getDistance().getValue()
            ))
            .collect(Collectors.toList());
    }
    
    /**
     * Find restaurants in specific area with filters
     */
    public List<Restaurant> findRestaurantsNearby(
            double longitude, 
            double latitude, 
            double radiusKm,
            String category,
            double minRating) {
        
        Point location = new Point(longitude, latitude);
        
        Query query = new Query();
        
        // Geospatial criteria

            Criteria.where("location")
                .nearSphere(location)
                .maxDistance(radiusKm / 6371.0)  // Convert to radians

            query.addCriteria(Criteria.where("category").is(category));
        }
        
        if (minRating > 0) {
            query.addCriteria(Criteria.where("rating").gte(minRating));
        }
        
        // Sort by distance
        query.with(Sort.by(Sort.Direction.ASC, "location"));
        query.limit(50);
        
        return mongoTemplate.find(query, Restaurant.class);
    }
```

## Best Practices Summary

### ✅ DO:

1. **Use derived query methods** for simple, readable queries
2. **Use @Query** for complex MongoDB-specific queries
3. **Use Criteria API** for dynamic query building
4. **Use Aggregation** for analytics and reporting
5. **Create indexes** on frequently queried fields
6. **Use text indexes** for full-text search
7. **Use geospatial indexes** for location-based queries
8. **Limit results** with pagination
9. **Project only needed fields** to reduce network transfer
10. **Test query performance** with explain()

### ❌ DON'T:

1. **Don't fetch all documents** without pagination
2. **Don't query without indexes** on large collections
3. **Don't use derived methods** for complex logic (use @Query)
4. **Don't ignore query performance** - use explain()
5. **Don't forget to index** embedded document fields
6. **Don't use regex** without indexes (slow)
7. **Don't ignore geospatial index types** - use GEO_2DSPHERE
8. **Don't query in loops** - use aggregation
9. **Don't skip field projection** for large documents
10. **Don't hardcode queries** - use dynamic criteria

## Interview Questions

**Q1: What are the different ways to query MongoDB in Spring Data?**

Four main approaches: (1) Derived query methods (findByFirstNameAndLastName) - simple, type-safe, (2) @Query annotation with JSON - MongoDB-specific queries, (3) Criteria API - dynamic query building programmatically, (4) Aggregation framework - complex analytics and joins. Choose based on complexity and dynamism requirements.

**Q2: How do you build dynamic queries in Spring Data MongoDB?**

Use Criteria API with MongoTemplate. Build Query object conditionally based on parameters: `Query query = new Query(); if (status != null) query.addCriteria(Criteria.where("status").is(status));` Add multiple criteria using andOperator/orOperator. Supports all MongoDB operators (gte, lte, regex, in, etc.) and allows dynamic sorting and pagination.

**Q3: Explain text search in MongoDB with Spring Data.**

Create text index with @TextIndexed on fields (with optional weights). Query using TextCriteria and TextQuery: `TextCriteria.forDefaultLanguage().matchingAny(term)` Use sortByScore() for relevance ranking. Supports phrase matching, term exclusion, language-specific search. Index all searchable text fields with appropriate weights.

**Q4: How do aggregation pipelines work in Spring Data MongoDB?**

Aggregation uses stages in sequence: match (filter), group (aggregate), project (shape output), sort, skip, limit, lookup (join). Build with Aggregation.newAggregation(). Each stage transforms documents. Use for analytics, reporting, joining collections. Example: group by status, count users, sort by count descending.

**Q5: What are geospatial queries in MongoDB and how to use them?**

Store location as GeoJsonPoint with @GeoSpatialIndexed. Near query finds locations within distance: `nearSphere(point).maxDistance(radius)`. Within queries find locations in area (circle, polygon, box). Use GeoResults for distance information. Index required for performance. Use GEO_2DSPHERE for Earth calculations.

Querying MongoDB in Spring provides multiple approaches:
