# MongoDB Change Streams

## Overview

MongoDB Change Streams provide real-time notifications when data changes in collections, databases, or entire deployments. Built on the oplog (operations log), change streams enable reactive applications, cache invalidation, real-time synchronization, and event-driven architectures without polling.

**Key Concept**: Change streams are MongoDB's native event streaming solution. They provide ordered, resumable streams of data changes with guaranteed delivery. Use change streams for real-time notifications, cache invalidation, data synchronization, and building event-driven microservices. Requires replica set or sharded cluster (MongoDB 3.6+).

---

## 1. Introduction to Change Streams

### What are Change Streams?

**Overview:**

```
Change Streams allow applications to:
- Watch for changes in real-time
- React to insert, update, delete, replace operations
- Filter changes with aggregation pipelines
- Resume from specific points using tokens
- Handle failovers automatically

Built on MongoDB Oplog:
- Ordered stream of database operations
- Survives network interruptions
- Guaranteed delivery with resume tokens

Requirements:
- MongoDB 3.6+ for replica sets
- MongoDB 4.0+ for sharded clusters
- Replica set or sharded cluster (not standalone)
```

### Change Stream Document Structure

**Change Event Format:**

```javascript
{
  "_id": {  // Resume token
    "_data": "8264A1F3B8000000012B022C0100296E5A10046..."
  },
  "operationType": "insert",  // insert, update, replace, delete
  "clusterTime": Timestamp(1688123456, 1),
  "ns": {  // Namespace
    "db": "mydb",
    "coll": "users"
  },
  "documentKey": {  // Document identifier
    "_id": ObjectId("507f1f77bcf86cd799439011")
  },
  "fullDocument": {  // Complete document (insert/replace/update with fullDocument)
    "_id": ObjectId("507f1f77bcf86cd799439011"),
    "name": "John Doe",
    "email": "john@example.com",
    "status": "ACTIVE"
  },
  "updateDescription": {  // For updates only
    "updatedFields": {
      "status": "INACTIVE"
    },
    "removedFields": ["tempField"]
  }
}
```

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class UserChangeStreamService {
    
    private final ReactiveMongoTemplate reactiveMongoTemplate;
    
    /**
     * Watch all changes to users collection
     */
    public Flux<ChangeStreamEvent<User>> watchAllChanges() {
        return reactiveMongoTemplate
            .changeStream(User.class)
            .listen()
            .doOnNext(event -> log.info("Change detected: {} - {}", 
                event.getOperationType(), 
                event.getBody()))
            .doOnError(error -> log.error("Error in change stream", error))
            .doOnComplete(() -> log.info("Change stream completed"));
    }
    
    /**
     * Watch specific operation types
     */
    public Flux<ChangeStreamEvent<User>> watchInserts() {
        ChangeStreamOptions options = ChangeStreamOptions.builder()
            .filter(Aggregation.newAggregation(
                Aggregation.match(Criteria.where("operationType").is("insert"))
            ))
            .build();
        
        return reactiveMongoTemplate
            .changeStream(User.class)
            .watchCollection(User.class)
            .withOptions(options)
            .listen();
    }
    
    /**
     * Watch with full document lookup
     */
    public Flux<ChangeStreamEvent<User>> watchWithFullDocument() {
        ChangeStreamOptions options = ChangeStreamOptions.builder()
            .returnFullDocumentOnUpdate()  // Include full document on updates
            .build();
        
        return reactiveMongoTemplate
            .changeStream(User.class)
            .withOptions(options)
            .listen();
    }
    
    /**
     * Process changes reactively
     */
    @PostConstruct
    public void startWatching() {
        watchAllChanges()
            .subscribe(
                event -> processChange(event),
                error -> log.error("Change stream error", error),
                () -> log.info("Change stream completed")
            );
    }
    
    private void processChange(ChangeStreamEvent<User> event) {
        String operation = event.getOperationType().getValue();
        User user = event.getBody();
        
        switch (operation) {
            case "insert":
                log.info("New user created: {}", user.getName());
                // Send welcome email, update cache, etc.
                break;
                
            case "update":
                log.info("User updated: {}", user.getName());
                // Invalidate cache, notify subscribers, etc.
                break;
                
            case "delete":
                log.info("User deleted: {}", event.getDocumentKey());
                // Cleanup related data, update cache, etc.
                break;
                
            case "replace":
                log.info("User replaced: {}", user.getName());
                break;
                
            default:
                log.info("Unknown operation: {}", operation);
        }
    }
}
```

## 4. Resume Tokens for Fault Tolerance

### Understanding Resume Tokens

**Resume Token Concept:**

```
Resume tokens enable:
1. Fault tolerance: Resume after crash
2. No missed events: Guaranteed delivery
3. Time travel: Resume from past point
4. Distributed processing: Multiple consumers

Resume Token Structure:
{
  "_data": "8264A1F3B8000000012B022C0100296E5A10046..."
}

Storage Options:
- Database (persistent across restarts)
- Redis (fast, distributed)
- File system (simple, local)
```

### Storing Resume Tokens

**Resume Token Entity:**

**Resumable Change Stream Service:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class ResumableChangeStreamService {
    
    private final ReactiveMongoTemplate reactiveMongoTemplate;
    private final ResumeTokenRepository resumeTokenRepository;
    
    private static final String STREAM_NAME = "user-changes";
    
    /**
     * Start change stream with resume capability
     */
    @PostConstruct
    public void startResumableStream() {
        watchWithResume()
            .subscribe(
                event -> processEvent(event),
                error -> {
                    log.error("Change stream error, will restart", error);
                    // Restart stream after error
                    restartAfterDelay();
                },
                () -> log.info("Change stream completed")
            );
    }
    
    /**
     * Watch with automatic resume token storage
     */
    public Flux<ChangeStreamEvent<User>> watchWithResume() {
        // Get last resume token
        Optional<ResumeToken> lastToken = resumeTokenRepository
            .findByStreamName(STREAM_NAME);
        
        ChangeStreamOptions.ChangeStreamOptionsBuilder optionsBuilder = 
            ChangeStreamOptions.builder();
        
        // Resume from last token if exists
        if (lastToken.isPresent() && lastToken.get().getToken() != null) {
            BsonDocument resumeToken = BsonDocument.parse(lastToken.get().getToken());
            optionsBuilder.resumeAfter(resumeToken);
            
            log.info("Resuming change stream from token: {}", 
                lastToken.get().getLastUpdated());
        } else {
            log.info("Starting new change stream");
        }
        
        return reactiveMongoTemplate
            .changeStream(User.class)
            .withOptions(optionsBuilder.build())
            .listen()
            .doOnNext(event -> saveResumeToken(event));
    }
    
    /**
     * Save resume token after each event
     */
    private void saveResumeToken(ChangeStreamEvent<User> event) {
        BsonDocument resumeToken = event.getResumeToken();
        
        if (resumeToken != null) {
            ResumeToken token = resumeTokenRepository
                .findByStreamName(STREAM_NAME)
                .orElse(new ResumeToken());
            
            token.setStreamName(STREAM_NAME);
            token.setToken(resumeToken.toJson());
            token.setLastUpdated(LocalDateTime.now());
            token.setStatus("ACTIVE");
            
            resumeTokenRepository.save(token);
        }
    }
    
    /**
     * Process event and update token
     */
    private void processEvent(ChangeStreamEvent<User> event) {
        try {
            // Process the change
            log.info("Processing change: {} - {}", 
                event.getOperationType(), 
                event.getBody());
            
            // Your business logic here
            
        } catch (Exception e) {
            log.error("Error processing event", e);
            // Token already saved, can retry this event
        }
    }
    
    /**
     * Restart stream after error
     */
    private void restartAfterDelay() {
        try {
            Thread.sleep(5000);  // Wait 5 seconds
            startResumableStream();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }
}
```

### Resume Token Best Practices

**Robust Token Management:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class TokenManagementService {
    
    private final ResumeTokenRepository resumeTokenRepository;
    private final ReactiveMongoTemplate reactiveMongoTemplate;
    
    /**
     * Batch token updates (performance optimization)
     */
    public Flux<ChangeStreamEvent<User>> watchWithBatchedTokens() {
        AtomicInteger eventCount = new AtomicInteger(0);
        AtomicReference<BsonDocument> lastToken = new AtomicReference<>();
        
        return reactiveMongoTemplate
            .changeStream(User.class)
            .listen()
            .doOnNext(event -> {
                lastToken.set(event.getResumeToken());
                
                // Save token every 100 events (reduces writes)
                if (eventCount.incrementAndGet() % 100 == 0) {
                    saveTokenAsync(lastToken.get());
                }
            });
    }
    
    /**
     * Token expiration handling
     */
    public Flux<ChangeStreamEvent<User>> watchWithTokenExpiration() {
        Optional<ResumeToken> token = resumeTokenRepository
            .findByStreamName("user-changes");
        
        if (token.isPresent()) {
            LocalDateTime lastUpdated = token.get().getLastUpdated();
            Duration age = Duration.between(lastUpdated, LocalDateTime.now());
            
            // Token older than 24 hours - start fresh
            if (age.toHours() > 24) {
                log.warn("Resume token expired ({}h old), starting fresh", age.toHours());
                return startFreshStream();
            }
        }
        
        return resumeFromToken(token);
    }
    
    /**
     * Multiple consumer coordination
     */
    public Flux<ChangeStreamEvent<User>> watchWithConsumerId(String consumerId) {
        String streamName = "user-changes-" + consumerId;
        
        Optional<ResumeToken> token = resumeTokenRepository
            .findByStreamName(streamName);
        
        ChangeStreamOptions.ChangeStreamOptionsBuilder options = 
            ChangeStreamOptions.builder();
        
        token.ifPresent(t -> {
            BsonDocument resumeToken = BsonDocument.parse(t.getToken());
            options.resumeAfter(resumeToken);
        });
        
        return reactiveMongoTemplate
            .changeStream(User.class)
            .withOptions(options.build())
            .listen()
            .doOnNext(event -> saveTokenForConsumer(event, streamName));
    }
    
    private void saveTokenAsync(BsonDocument token) {
        // Async token save to avoid blocking
        CompletableFuture.runAsync(() -> {
            ResumeToken resumeToken = new ResumeToken();
            resumeToken.setStreamName("user-changes");
            resumeToken.setToken(token.toJson());
            resumeToken.setLastUpdated(LocalDateTime.now());
            
            resumeTokenRepository.save(resumeToken);
        });
    }
    
    private Flux<ChangeStreamEvent<User>> startFreshStream() {
        return reactiveMongoTemplate
            .changeStream(User.class)
            .listen();
    }
    
    private Flux<ChangeStreamEvent<User>> resumeFromToken(Optional<ResumeToken> token) {
        // Implementation
        return Flux.empty();
    }
```

## 6. Real-Time Data Synchronization

### Master-Slave Synchronization

**Sync Service:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class DataSynchronizationService {
    
    private final ReactiveMongoTemplate primaryTemplate;
    private final RestTemplate restTemplate;  // For external sync
    
    /**
     * Sync changes to secondary system
     */
    @PostConstruct
    public void startSynchronization() {
        syncToSecondarySystem()
            .subscribe(
                event -> log.info("Synced: {}", event.getOperationType()),
                error -> log.error("Sync error", error)
            );
    }
    
    private Flux<ChangeStreamEvent<User>> syncToSecondarySystem() {
        return primaryTemplate
            .changeStream(User.class)
            .listen()
            .doOnNext(event -> {
                String operation = event.getOperationType().getValue();
                User user = event.getBody();
                
                switch (operation) {
                    case "insert":
                        createInSecondary(user);
                        break;
                    case "update":
                    case "replace":
                        updateInSecondary(user);
                        break;
                    case "delete":
                        String deletedId = event.getDocumentKey().get("_id").asObjectId().getValue().toHexString();
                        deleteInSecondary(deletedId);
                        break;
                }
            })
            .retry(3);  // Retry on failures
    }
    
    private void createInSecondary(User user) {
        try {
            restTemplate.postForObject(
                "http://secondary-system/api/users",
                user,
                Void.class
            );
            log.info("Created user in secondary: {}", user.getId());
        } catch (Exception e) {
            log.error("Failed to create in secondary", e);
            throw new SyncFailedException("Create failed", e);
        }
    }
    
    private void updateInSecondary(User user) {
        try {
            restTemplate.put(
                "http://secondary-system/api/users/" + user.getId(),
                user
            );
            log.info("Updated user in secondary: {}", user.getId());
        } catch (Exception e) {
            log.error("Failed to update in secondary", e);
            throw new SyncFailedException("Update failed", e);
        }
    }
    
    private void deleteInSecondary(String userId) {
        try {
            restTemplate.delete(
                "http://secondary-system/api/users/" + userId
            );
            log.info("Deleted user in secondary: {}", userId);
        } catch (Exception e) {
            log.error("Failed to delete in secondary", e);
            throw new SyncFailedException("Delete failed", e);
        }
    }
}

class SyncFailedException extends RuntimeException {
    public SyncFailedException(String message, Throwable cause) {
        super(message, cause);
    }
}
```

### Bi-Directional Synchronization

**Two-Way Sync:**

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class BiDirectionalSyncService {
    
    private final ReactiveMongoTemplate mongoTemplate;
    private final KafkaTemplate<String, ChangeEvent> kafkaTemplate;
    
    /**
     * Sync MongoDB changes to Kafka
     */
    @PostConstruct
    public void syncToKafka() {
        mongoTemplate
            .changeStream(User.class)
            .listen()
            .doOnNext(event -> {
                ChangeEvent changeEvent = new ChangeEvent();
                changeEvent.setOperation(event.getOperationType().getValue());
                changeEvent.setEntity("user");
                changeEvent.setDocumentId(
                    event.getDocumentKey().get("_id").asObjectId().getValue().toHexString()
                );
                changeEvent.setData(event.getBody());
                changeEvent.setTimestamp(LocalDateTime.now());
                
                // Publish to Kafka
                kafkaTemplate.send("user-changes", changeEvent);
                
                log.info("Published change to Kafka: {}", changeEvent.getOperation());
            })
            .subscribe();
    }
    
    /**
     * Consume changes from Kafka and apply to MongoDB
     */
    @KafkaListener(topics = "external-user-changes")
    public void syncFromKafka(ChangeEvent event) {
        if ("external-system".equals(event.getSource())) {
            // Apply changes from external system
            switch (event.getOperation()) {
                case "insert":
                    User user = (User) event.getData();
                    mongoTemplate.insert(user).subscribe();
                    break;
                case "update":
                    User updatedUser = (User) event.getData();
                    mongoTemplate.save(updatedUser).subscribe();
                    break;
                case "delete":
                    mongoTemplate.remove(
                        new Query(Criteria.where("_id").is(event.getDocumentId())),
                        User.class
                    ).subscribe();
                    break;
            }
            
            log.info("Applied external change: {}", event.getOperation());
        }
    }
}

@Data
class ChangeEvent {
    private String operation;
    private String entity;
    private String documentId;
    private Object data;
    private String source;
    private LocalDateTime timestamp;
}
```

### Cache Invalidation

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class CacheInvalidationService {
    
    private final ReactiveMongoTemplate mongoTemplate;
    private final RedisTemplate<String, Object> redisTemplate;
    
    /**
     * Invalidate cache on user changes
     */
    @PostConstruct
    public void setupCacheInvalidation() {

            .changeStream(User.class)
            .listen()
            .doOnNext(event -> invalidateUserCache(event))
            .subscribe();
    }
    
    private void invalidateUserCache(ChangeStreamEvent<User> event) {
        String operation = event.getOperationType().getValue();
        String userId = event.getDocumentKey()
            .get("_id")
            .asObjectId()
            .getValue()
            .toHexString();
        
        switch (operation) {
            case "update":
            case "replace":
                // Invalidate specific user cache
                String cacheKey = "user:" + userId;
                redisTemplate.delete(cacheKey);
                log.info("Invalidated cache for user: {}", userId);
                
                // Also invalidate list caches containing this user
                User user = event.getBody();
                if (user != null && user.getStatus() != null) {
                    redisTemplate.delete("users:status:" + user.getStatus());
                }
                break;
                
            case "delete":
                // Remove from cache
                redisTemplate.delete("user:" + userId);
                log.info("Removed deleted user from cache: {}", userId);
                break;
                
            case "insert":
                // Invalidate list caches (new user added)
                redisTemplate.keys("users:*").forEach(redisTemplate::delete);
                log.info("Invalidated user list caches");
                break;
        }
    }
    
    /**
     * Invalidate product cache with category awareness
     */
    public void setupProductCacheInvalidation() {
        mongoTemplate
            .changeStream(Product.class)
            .listen()
            .doOnNext(event -> {
                Product product = event.getBody();
                
                if (product != null) {
                    // Invalidate product cache
                    redisTemplate.delete("product:" + product.getId());
                    
                    // Invalidate category caches
                    redisTemplate.delete("products:category:" + product.getCategory());
                    
                    // Invalidate search results
                    redisTemplate.keys("products:search:*").forEach(redisTemplate::delete);
                    
                    log.info("Invalidated caches for product: {}", product.getId());
                }
            })
            .subscribe();
    }
}
```

```java
@Service
@RequiredArgsConstructor
@Slf4j
public class EventDrivenPublisher {
    
    private final ReactiveMongoTemplate mongoTemplate;
    private final ApplicationEventPublisher eventPublisher;
    
    /**
     * Publish domain events based on changes
     */
    @PostConstruct
    public void publishDomainEvents() {
        watchOrderChanges();
        watchPaymentChanges();
        watchInventoryChanges();
    }
    
    private void watchOrderChanges() {
        mongoTemplate
            .changeStream(Order.class)
            .listen()
            .doOnNext(event -> {
                Order order = event.getBody();
                String operation = event.getOperationType().getValue();
                
                switch (operation) {
                    case "insert":
                        eventPublisher.publishEvent(
                            new OrderCreatedEvent(this, order)
                        );
                        break;
                        
                    case "update":
                        // Check if status changed
                        if (hasStatusChanged(event)) {
                            eventPublisher.publishEvent(
                                new OrderStatusChangedEvent(
                                    this, 
                                    order.getId(), 
                                    order.getStatus()
                                )
                            );
                        }
                        break;
                }
            })
            .subscribe();
    }
    
    private void watchPaymentChanges() {
        mongoTemplate
            .changeStream(Payment.class)
            .listen()
            .doOnNext(event -> {
                Payment payment = event.getBody();
                
                if ("update".equals(event.getOperationType().getValue()) &&
                    "COMPLETED".equals(payment.getStatus())) {
                    
                    eventPublisher.publishEvent(
                        new PaymentCompletedEvent(this, payment)
                    );
                }
            })
            .subscribe();
    }
    
    private void watchInventoryChanges() {
        mongoTemplate
            .changeStream(Inventory.class)
            .listen()
            .filter(event -> {
                Inventory inventory = event.getBody();
                return inventory != null && inventory.getQuantity() < 10;
            })
            .doOnNext(event -> {
                Inventory inventory = event.getBody();
                
                eventPublisher.publishEvent(
                    new LowInventoryEvent(
                        this, 
                        inventory.getProductId(), 
                        inventory.getQuantity()
                    )
                );
            })
            .subscribe();
    }
    
    private boolean hasStatusChanged(ChangeStreamEvent<Order> event) {
        Document updateDescription = event.getRaw().get("updateDescription", Document.class);
        if (updateDescription != null) {
            Document updatedFields = updateDescription.get("updatedFields", Document.class);
            return updatedFields != null && updatedFields.containsKey("status");
        }
        return false;
    }
}
```

## Best Practices Summary

### ✅ DO:

1. **Use resume tokens** for fault tolerance
2. **Filter at MongoDB** level using aggregation pipelines
3. **Batch token updates** (every N events) for performance
4. **Handle errors gracefully** with retry logic
5. **Use specific collection watches** when possible
6. **Monitor change stream lag** and performance
7. **Set up health checks** for stream status
8. **Use connection pooling** for better performance
9. **Test failover scenarios** thoroughly
10. **Document event schemas** for consumers

### ❌ DON'T:

1. **Don't use on standalone** MongoDB (requires replica set)
2. **Don't process synchronously** without backpressure handling
3. **Don't ignore resume tokens** - lose fault tolerance
4. **Don't filter in application** if can filter in MongoDB
5. **Don't create too many streams** - resource intensive
6. **Don't perform heavy operations** in change stream handlers
7. **Don't ignore errors** without retry mechanism
8. **Don't skip monitoring** - critical for production
9. **Don't forget cleanup** when stream no longer needed
10. **Don't use for high-frequency** changes (>10k/sec per collection)

## Interview Questions

**Q1: What are MongoDB Change Streams and when should you use them?**

Change Streams provide real-time notifications of data changes using MongoDB's oplog. Use for: (1) cache invalidation when data changes, (2) event-driven microservices, (3) real-time synchronization between systems, (4) audit logging, (5) real-time notifications. Requires replica set or sharded cluster (MongoDB 3.6+). Better than polling - guaranteed delivery, ordered events, resumable with tokens.

**Q2: How do resume tokens work in Change Streams?**

Resume tokens enable fault-tolerant streaming by marking position in oplog. Each change event includes token. Save token after processing event. On restart/failure, resume from last saved token using `resumeAfter()`. Guarantees no missed events. Store tokens in database, Redis, or file. Batch updates (every 100 events) for performance. Tokens expire after ~8 hours oplog retention.

**Q3: How do you filter Change Streams efficiently?**

Use aggregation pipelines in `ChangeStreamOptions.filter()` - MongoDB filters before sending to application. Filter by: (1) operationType (insert/update/delete), (2) field values in fullDocument, (3) specific field updates in updateDescription, (4) document IDs in documentKey. Filtering at MongoDB level reduces network traffic and application load. Always use `returnFullDocumentOnUpdate()` when filtering on document fields.

**Q4: What are the performance implications of Change Streams?**

Change Streams: (1) Read from oplog (minimal database impact), (2) Network bandwidth for streaming events, (3) Application resources for processing, (4) Resume token storage overhead. Optimize by: filtering at MongoDB, batching token updates, using reactive streams with backpressure, processing async, monitoring lag. Not suitable for >10k changes/sec per collection - use CDC tools instead.

**Q5: How do you implement cache invalidation with Change Streams?**

Watch collection with change stream, on update/delete operations invalidate corresponding cache keys. Example: User update → delete Redis key `user:{id}`, also invalidate list caches containing user. Use filters to watch only relevant fields. Process async to avoid blocking. Handle retry on cache failures. Benefits: automatic invalidation, no stale data, no polling overhead, works across instances.
