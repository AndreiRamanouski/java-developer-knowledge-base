# Spring Data MongoDB Setup and Configuration

## Overview

Spring Data MongoDB provides seamless integration between Spring Boot applications and MongoDB databases. It offers repository abstractions, template operations, and comprehensive configuration options for production deployments including replica sets, authentication, and fine-grained read/write controls.

**Key Concept**: Spring Data MongoDB provides two main approaches - MongoRepository for declarative queries and MongoTemplate for programmatic operations. Choose based on complexity: repositories for CRUD and simple queries, template for complex aggregations and bulk operations.

### Custom Configuration

**Override Auto-Configuration:**

```java
@Configuration
@EnableMongoRepositories(basePackages = "com.example.repository")
public class MongoConfig extends AbstractMongoClientConfiguration {
    
    @Value("${spring.data.mongodb.database}")
    private String database;
    
    @Value("${spring.data.mongodb.uri}")
    private String uri;
    
    @Override
    protected String getDatabaseName() {
        return database;
    }
    
    @Override
    public MongoClient mongoClient() {
        ConnectionString connectionString = new ConnectionString(uri);
        
        MongoClientSettings settings = MongoClientSettings.builder()
            .applyConnectionString(connectionString)
            .applyToConnectionPoolSettings(builder -> 
                builder.maxSize(100)
                       .minSize(10)
                       .maxWaitTime(2, TimeUnit.MINUTES)
            )
            .applyToSocketSettings(builder ->
                builder.connectTimeout(10, TimeUnit.SECONDS)
                       .readTimeout(10, TimeUnit.SECONDS)
            )
            .build();
        
        return MongoClients.create(settings);
    }
    
    @Bean
    public MongoTemplate mongoTemplate() throws Exception {
        return new MongoTemplate(mongoClient(), getDatabaseName());
    }
}
```

## 2. MongoTemplate vs MongoRepository

### MongoRepository (Declarative)

**Repository Interface:**

```java
@Repository
public interface UserRepository extends MongoRepository<User, String> {
    
    // Query method - Spring generates implementation
    List<User> findByEmail(String email);
    
    // Multiple conditions
    List<User> findByFirstNameAndLastName(String firstName, String lastName);
    
    // Pattern matching
    List<User> findByEmailContaining(String emailPart);
    
    // Ordering
    List<User> findByLastNameOrderByFirstNameAsc(String lastName);
    
    // Pagination
    Page<User> findByAgeGreaterThan(int age, Pageable pageable);
    
    // Custom query using @Query
    @Query("{ 'email': ?0 }")
    User findUserByEmail(String email);
    
    // Query with projection
    @Query(value = "{ 'age': { $gte: ?0 } }", fields = "{ 'firstName': 1, 'lastName': 1 }")
    List<User> findUsersOlderThan(int age);
    
    // Update query
    @Query("{ 'email': ?0 }")
    @Update("{ $set: { 'status': ?1 } }")
    long updateStatusByEmail(String email, String status);
    
    // Aggregation
    @Aggregation(pipeline = {
        "{ $match: { 'status': 'ACTIVE' } }",
        "{ $group: { _id: '$city', count: { $sum: 1 } } }"
    })
    List<CityCount> countUsersByCity();
    
    // Delete query
    long deleteByEmail(String email);
    
    // Exists query
    boolean existsByEmail(String email);
    
    // Count query
    long countByStatus(String status);
}
```

### MongoTemplate (Programmatic)

**Complex Queries with MongoTemplate:**

```java
@Service
@RequiredArgsConstructor
public class UserTemplateService {
    
    private final MongoTemplate mongoTemplate;
    
    /**
     * Simple find operation
     */
    public List<User> findActiveUsers() {
        Query query = new Query();
        query.addCriteria(Criteria.where("status").is("ACTIVE"));
        return mongoTemplate.find(query, User.class);
    }
    
    /**
     * Complex query with multiple criteria
     */
    public List<User> findUsersByCriteria(String city, int minAge, int maxAge) {
        Query query = new Query();
        query.addCriteria(
            Criteria.where("city").is(city)
                .and("age").gte(minAge).lte(maxAge)
                .and("status").is("ACTIVE")
        );
        query.with(Sort.by(Sort.Direction.ASC, "firstName"));
        query.limit(100);
        
        return mongoTemplate.find(query, User.class);
    }
    
    /**
     * Pagination with template
     */
    public Page<User> findUsersWithPagination(int page, int size) {
        Pageable pageable = PageRequest.of(page, size);
        
        Query query = new Query().with(pageable);
        query.addCriteria(Criteria.where("status").is("ACTIVE"));
        
        List<User> users = mongoTemplate.find(query, User.class);
        long count = mongoTemplate.count(query.skip(-1).limit(-1), User.class);
        
        return new PageImpl<>(users, pageable, count);
    }
    
    /**
     * Projection - select specific fields
     */
    public List<UserSummary> getUserSummaries() {
        Query query = new Query();
        query.fields()
            .include("firstName", "lastName", "email")
            .exclude("_id");
        
        return mongoTemplate.find(query, UserSummary.class, "users");
    }
    
    /**
     * Update operation
     */
    public UpdateResult updateUserCity(String email, String newCity) {
        Query query = new Query(Criteria.where("email").is(email));
        Update update = new Update()
            .set("city", newCity)
            .set("updatedAt", LocalDateTime.now())
            .inc("version", 1);
        
        return mongoTemplate.updateFirst(query, update, User.class);
    }
    
    /**
     * Update multiple documents
     */
    public UpdateResult activateUsersInCity(String city) {
        Query query = new Query(Criteria.where("city").is(city));
        Update update = new Update()
            .set("status", "ACTIVE")
            .set("updatedAt", LocalDateTime.now());
        
        return mongoTemplate.updateMulti(query, update, User.class);
    }
    
    /**
     * Upsert operation
     */
    public UpdateResult upsertUser(String email, User user) {
        Query query = new Query(Criteria.where("email").is(email));
        Update update = new Update()
            .set("firstName", user.getFirstName())
            .set("lastName", user.getLastName())
            .set("age", user.getAge())
            .set("updatedAt", LocalDateTime.now())
            .setOnInsert("createdAt", LocalDateTime.now())
            .setOnInsert("status", "ACTIVE");
        
        return mongoTemplate.upsert(query, update, User.class);
    }
    
    /**
     * Delete operation
     */
    public DeleteResult deleteInactiveUsers() {
        Query query = new Query(Criteria.where("status").is("INACTIVE"));
        return mongoTemplate.remove(query, User.class);
    }
    
    /**
     * Aggregation pipeline
     */
    public List<CityStatistics> getCityStatistics() {
        Aggregation aggregation = Aggregation.newAggregation(
            // Match active users
            Aggregation.match(Criteria.where("status").is("ACTIVE")),
            
            // Group by city
            Aggregation.group("city")
                .count().as("userCount")
                .avg("age").as("averageAge")
                .min("age").as("minAge")
                .max("age").as("maxAge"),
            
            // Project fields
            Aggregation.project()
                .and("_id").as("city")
                .and("userCount").as("totalUsers")
                .and("averageAge").as("avgAge")
                .and("minAge").as("minimumAge")
                .and("maxAge").as("maximumAge"),
            
            // Sort by user count descending
            Aggregation.sort(Sort.Direction.DESC, "totalUsers"),
            
            // Limit to top 10 cities
            Aggregation.limit(10)
        );
        
        AggregationResults<CityStatistics> results = 
            mongoTemplate.aggregate(aggregation, "users", CityStatistics.class);
        
        return results.getMappedResults();
    }
    
    /**
     * Text search
     */
    public List<User> searchUsersByText(String searchTerm) {
        TextCriteria criteria = TextCriteria.forDefaultLanguage()
            .matchingAny(searchTerm);
        
        Query query = TextQuery.queryText(criteria)
            .sortByScore()
            .with(PageRequest.of(0, 20));
        
        return mongoTemplate.find(query, User.class);
    }
    
    /**
     * Geospatial query - find nearby users
     */
    public List<User> findNearbyUsers(double longitude, double latitude, double maxDistance) {
        Query query = new Query();
        query.addCriteria(
            Criteria.where("location")
                .nearSphere(new Point(longitude, latitude))
                .maxDistance(maxDistance)
        );
        
        return mongoTemplate.find(query, User.class);
    }
    
    /**
     * Bulk operations
     */
    @Transactional
    public void bulkUpdateUsers(List<User> users) {
        BulkOperations bulkOps = mongoTemplate.bulkOps(
            BulkOperations.BulkMode.UNORDERED, 
            User.class
        );
        
        for (User user : users) {
            Query query = new Query(Criteria.where("_id").is(user.getId()));
            Update update = new Update()
                .set("firstName", user.getFirstName())
                .set("lastName", user.getLastName())
                .set("updatedAt", LocalDateTime.now());
            
            bulkOps.updateOne(query, update);
        }
        
        BulkWriteResult result = bulkOps.execute();
        
        System.out.printf("Modified %d documents%n", result.getModifiedCount());
    }
}

@Data
class CityStatistics {
    private String city;
    private long totalUsers;
    private double avgAge;
    private int minimumAge;
    private int maximumAge;
}

@Data
class UserSummary {
    private String firstName;
    private String lastName;
    private String email;
}
```

### When to Use Each

**Use MongoRepository When:**

```
✅ Simple CRUD operations
✅ Query methods with clear naming
✅ Basic filtering and sorting
✅ Standard pagination
✅ Type-safe queries preferred
✅ Less code needed
✅ Domain-driven design approach
```

**Use MongoTemplate When:**

```
✅ Complex aggregations
✅ Dynamic query building
✅ Bulk operations
✅ Geospatial queries
✅ Text search
✅ Fine-grained control needed
✅ Custom update logic
✅ Performance optimization required
```

**Comparison Table:**

|Feature|MongoRepository|MongoTemplate|
|---|---|---|
|**CRUD**|⭐⭐⭐⭐⭐ Easy|⭐⭐⭐ Verbose|
|**Simple Queries**|⭐⭐⭐⭐⭐ Method names|⭐⭐⭐ Build queries|
|**Complex Queries**|⭐⭐⭐ @Query annotation|⭐⭐⭐⭐⭐ Full control|
|**Aggregations**|⭐⭐⭐ @Aggregation|⭐⭐⭐⭐⭐ Pipeline builder|
|**Dynamic Queries**|⭐⭐ Difficult|⭐⭐⭐⭐⭐ Excellent|
|**Bulk Operations**|❌ Not supported|⭐⭐⭐⭐⭐ Built-in|
|**Type Safety**|⭐⭐⭐⭐⭐ Compile-time|⭐⭐⭐ Runtime|
|**Learning Curve**|⭐⭐⭐⭐⭐ Easy|⭐⭐⭐ Moderate|
|**Code Volume**|⭐⭐⭐⭐⭐ Minimal|⭐⭐⭐ More code|

## 3. Connection String Configuration

### URI Format

**Standard Connection String:**

```
mongodb://[username:password@]host1[:port1][,...hostN[:portN]][/[database][?options]]
```

**Components:**

```
Protocol:    mongodb:// or mongodb+srv://
Credentials: username:password (optional)
Hosts:       host1:port1,host2:port2,host3:port3
Database:    database name (optional)
Options:     ?key=value&key2=value2
```

### Basic Connection Strings

**Local MongoDB:**

```yaml
spring:
  data:
    mongodb:
      uri: mongodb://localhost:27017/mydb
```

**MongoDB with Authentication:**

```yaml
spring:
  data:
    mongodb:
      uri: mongodb://myuser:mypassword@localhost:27017/mydb?authSource=admin
```

**MongoDB Atlas (Cloud):**

```yaml
spring:
  data:
    mongodb:
      uri: mongodb+srv://myuser:mypassword@cluster0.mongodb.net/mydb?retryWrites=true&w=majority
```

**Multiple Hosts (Replica Set):**

```yaml
spring:
  data:
    mongodb:
      uri: mongodb://host1:27017,host2:27017,host3:27017/mydb?replicaSet=rs0
```

### Programmatic Configuration

**Connection String Builder:**

```java
@Configuration
public class MongoConnectionConfig {
    
    @Value("${mongodb.host}")
    private String host;
    
    @Value("${mongodb.port}")
    private int port;
    
    @Value("${mongodb.database}")
    private String database;
    
    @Value("${mongodb.username}")
    private String username;
    
    @Value("${mongodb.password}")
    private String password;
    
    @Bean
    public MongoClient mongoClient() {
        String connectionString = buildConnectionString();
        
        MongoClientSettings settings = MongoClientSettings.builder()
            .applyConnectionString(new ConnectionString(connectionString))
            .applyToConnectionPoolSettings(builder ->
                builder.maxSize(100)
                       .minSize(10)
                       .maxWaitTime(2, TimeUnit.MINUTES)
                       .maxConnectionLifeTime(30, TimeUnit.MINUTES)
                       .maxConnectionIdleTime(10, TimeUnit.MINUTES)
            )
            .applyToSocketSettings(builder ->
                builder.connectTimeout(10, TimeUnit.SECONDS)
                       .readTimeout(30, TimeUnit.SECONDS)
            )
            .applyToServerSettings(builder ->
                builder.heartbeatFrequency(10, TimeUnit.SECONDS)
                       .minHeartbeatFrequency(500, TimeUnit.MILLISECONDS)
            )
            .readPreference(ReadPreference.secondaryPreferred())
            .writeConcern(WriteConcern.MAJORITY.withWTimeout(5, TimeUnit.SECONDS))
            .readConcern(ReadConcern.MAJORITY)
            .retryWrites(true)
            .retryReads(true)
            .build();
        
        return MongoClients.create(settings);
    }
    
    private String buildConnectionString() {
        return String.format(
            "mongodb://%s:%s@%s:%d/%s?authSource=admin",
            username, password, host, port, database
        );
    }
}
```

### Connection Pooling

**Pool Configuration:**

```java
@Bean
public MongoClient mongoClient() {
    MongoClientSettings settings = MongoClientSettings.builder()
        .applyToConnectionPoolSettings(builder -> {
            // Maximum number of connections
            builder.maxSize(100);
            
            // Minimum number of connections
            builder.minSize(10);
            
            // Max wait time for connection from pool
            builder.maxWaitTime(2, TimeUnit.MINUTES);
            
            // Max time connection can be idle
            builder.maxConnectionIdleTime(10, TimeUnit.MINUTES);
            
            // Max lifetime of connection
            builder.maxConnectionLifeTime(30, TimeUnit.MINUTES);
            
            // Connection pool listeners for monitoring
            builder.addConnectionPoolListener(new ConnectionPoolListener() {
                @Override
                public void connectionPoolCreated(ConnectionPoolCreatedEvent event) {
                    log.info("Connection pool created: {}", event.getServerId());
                }
                
                @Override
                public void connectionCheckedOut(ConnectionCheckedOutEvent event) {
                    log.debug("Connection checked out: {}", event.getConnectionId());
                }
                
                @Override
                public void connectionCheckedIn(ConnectionCheckedInEvent event) {
                    log.debug("Connection checked in: {}", event.getConnectionId());
                }
            });
        })
        .build();
    
    return MongoClients.create(settings);
}
```

## 4. Replica Set Configuration

### Understanding Replica Sets

**Replica Set Architecture:**

```
┌─────────────────────────────────────────────┐
│          MongoDB Replica Set (rs0)         │
├─────────────────────────────────────────────┤
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │ PRIMARY  │  │SECONDARY │  │SECONDARY │ │
│  │  Node 1  │  │  Node 2  │  │  Node 3  │ │
│  │          │  │          │  │          │ │
│  │ Read/    │  │ Read     │  │ Read     │ │
│  │ Write    │  │ Only*    │  │ Only*    │ │
│  └─────┬────┘  └─────┬────┘  └─────┬────┘ │
│        │             │              │      │
│        └─────────────┴──────────────┘      │
│              Replication                    │
└─────────────────────────────────────────────┘

* If read preference allows
```

### Replica Set Configuration Class

```java
@Configuration
@ConfigurationProperties(prefix = "mongodb.replica-set")
@Data
public class ReplicaSetConfig {
    
    private String name;
    private List<String> members;
    private String username;
    private String password;
    private String database;
    private String authSource;
    
    @Bean
    public MongoClient replicaSetMongoClient() {
        // Build connection string with all members
        String hosts = String.join(",", members);
        String connectionString = String.format(
            "mongodb://%s:%s@%s/%s?replicaSet=%s&authSource=%s",
            username, password, hosts, database, name, authSource
        );
        
        MongoClientSettings settings = MongoClientSettings.builder()
            .applyConnectionString(new ConnectionString(connectionString))
            .applyToClusterSettings(builder ->
                builder.serverSelectionTimeout(30, TimeUnit.SECONDS)
                       .localThreshold(15, TimeUnit.MILLISECONDS)
            )
            .applyToServerSettings(builder ->
                builder.heartbeatFrequency(10, TimeUnit.SECONDS)
                       .minHeartbeatFrequency(500, TimeUnit.MILLISECONDS)
            )
            .retryWrites(true)
            .retryReads(true)
            .build();
        
        return MongoClients.create(settings);
    }
}
```

## 6. Read Preference and Write Concern

### Read Preference Deep Dive

**Read Preference Options:**

|Mode|Description|Use Case|Consistency|
|---|---|---|---|
|**primary**|Read from primary only|Strong consistency required|Strong|
|**primaryPreferred**|Primary if available, else secondary|Failover tolerance|Strong → Eventual|
|**secondary**|Read from secondary only|Offload reads from primary|Eventual|
|**secondaryPreferred**|Secondary if available, else primary|Most common for reads|Eventual → Strong|
|**nearest**|Lowest network latency|Geo-distributed apps|Eventual|

**Per-Query Read Preference:**

### Write Concern Configuration

**Write Concern Levels:**

|Level|Description|Use Case|Performance|
|---|---|---|---|
|**w: 0**|Unacknowledged|Logs, metrics (loss acceptable)|Fastest|
|**w: 1**|Acknowledged by primary|Default, balanced|Fast|
|**w: "majority"**|Majority of replica set|Critical data|Slower|
|**w: N**|N replicas acknowledge|Custom durability|Configurable|

**Write Concern with Journal:**

```java
@Configuration
public class WriteConcernConfig {
    
    /**
     * Unacknowledged writes (fastest, no guarantee)
     */
    @Bean("unacknowledgedTemplate")
    public MongoTemplate unacknowledgedTemplate(MongoClient mongoClient) {
        MongoTemplate template = new MongoTemplate(mongoClient, "mydb");
        template.setWriteConcern(WriteConcern.UNACKNOWLEDGED);
        return template;
    }
    
    /**
     * Acknowledged by primary (default)
     */
    @Bean("acknowledgedTemplate")
    public MongoTemplate acknowledgedTemplate(MongoClient mongoClient) {
        MongoTemplate template = new MongoTemplate(mongoClient, "mydb");
        template.setWriteConcern(WriteConcern.ACKNOWLEDGED);
        return template;
    }
    
    /**
     * Majority write concern (most durable)
     */
    @Bean("majorityTemplate")
    public MongoTemplate majorityTemplate(MongoClient mongoClient) {
        MongoTemplate template = new MongoTemplate(mongoClient, "mydb");
        
        WriteConcern writeConcern = WriteConcern.MAJORITY
            .withWTimeout(5, TimeUnit.SECONDS)  // Timeout
            .withJournal(true);  // Wait for journal
        
        template.setWriteConcern(writeConcern);
        return template;
    }
    
    /**
     * Custom write concern (wait for 2 replicas)
     */
    @Bean("customTemplate")
    public MongoTemplate customTemplate(MongoClient mongoClient) {
        MongoTemplate template = new MongoTemplate(mongoClient, "mydb");
        
        WriteConcern writeConcern = new WriteConcern(2)  // Wait for 2 nodes
            .withWTimeout(3, TimeUnit.SECONDS)
            .withJournal(true);
        
        template.setWriteConcern(writeConcern);
        return template;
    }
}
```

```java
     * Critical financial transaction

            return criticalTemplate.save(order);

                "Order could not be safely persisted", e

        }
    }
}
```

## Interview Questions

**Q1: What's the difference between MongoRepository and MongoTemplate?**

MongoRepository is declarative with query methods derived from method names, best for simple CRUD operations. MongoTemplate is programmatic with full control, best for complex queries, aggregations, and bulk operations. Use Repository for standard operations (80% of cases), Template for complex scenarios (20%).

**Q2: Explain MongoDB replica set configuration in Spring Boot.**

Replica set has one primary (reads/writes) and multiple secondaries (reads only with appropriate read preference). Configure via connection string with all members: `mongodb://host1,host2,host3/db?replicaSet=rs0`. Spring automatically handles failover when primary becomes unavailable. Use secondaryPreferred read preference to distribute read load.

**Q3: What are the different read preference modes and when to use each?**

Primary (strong consistency, critical operations), PrimaryPreferred (failover tolerance), Secondary (offload reads, analytics), SecondaryPreferred (most common, balanced load), Nearest (geo-distributed, lowest latency). Choose based on consistency requirements vs read distribution needs.

**Q4: Explain write concern levels in MongoDB.**

Write concern controls acknowledgment level: w=0 (unacknowledged, fastest), w=1 (primary only, default), w="majority" (majority of replica set, most durable). Use majority for critical data, acknowledged for normal operations, unacknowledged only for non-critical logs. Add journal=true for disk persistence.

**Q5: How do you configure authentication for MongoDB in Spring Boot?**

Use connection string with credentials: `mongodb://user:pass@host:27017/db?authSource=admin&authMechanism=SCRAM-SHA-256`. Default is SCRAM-SHA-256 (recommended). Also supports X.509 certificates, LDAP, and AWS IAM. Store credentials in environment variables or secrets management, never hardcode.
