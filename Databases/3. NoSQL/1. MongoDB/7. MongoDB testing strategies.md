# MongoDB Testing Strategies

## Overview

Testing MongoDB applications requires different strategies for different scenarios: unit tests with mocks, integration tests with embedded databases, and end-to-end tests with production-like environments. Choose the right testing approach based on what you're testing - repositories, complex queries, transactions, or performance.

**Key Concept**: Use embedded MongoDB for fast unit tests, Testcontainers for production-like integration tests, and mocks for pure unit testing. Layer your tests: fast unit tests (90%), slower integration tests (9%), and slow end-to-end tests (1%). Always test with realistic data volumes.

### Testing Complex Queries

**Custom Query Tests:**

```java
@DataMongoTest
@ActiveProfiles("test")
class UserComplexQueryTest {
    
    @Autowired
    private MongoTemplate mongoTemplate;
    
    @BeforeEach
    void setUp() {
        mongoTemplate.dropCollection(User.class);
    }
    
    @Test
    @DisplayName("Should find users with complex criteria")
    void testComplexQuery() {
        // Given
        createTestData();
        
        // When
        Query query = new Query();
        query.addCriteria(
            new Criteria().andOperator(
                Criteria.where("status").is("ACTIVE"),
                Criteria.where("age").gte(25).lte(35)
            )
        );
        
        List<User> users = mongoTemplate.find(query, User.class);
        
        // Then
        assertThat(users).hasSize(2);
        assertThat(users)
            .extracting(User::getAge)
            .allMatch(age -> age >= 25 && age <= 35);
    }
    
    @Test
    @DisplayName("Should execute aggregation pipeline")
    void testAggregation() {
        // Given
        createTestData();
        
        // When
        Aggregation aggregation = Aggregation.newAggregation(
            Aggregation.match(Criteria.where("status").is("ACTIVE")),
            Aggregation.group("status")
                .count().as("count")
                .avg("age").as("averageAge"),
            Aggregation.sort(Sort.Direction.DESC, "count")
        );
        
        AggregationResults<Document> results = mongoTemplate.aggregate(
            aggregation, "users", Document.class
        );
        
        // Then
        assertThat(results.getMappedResults()).isNotEmpty();
        Document result = results.getMappedResults().get(0);
        assertThat(result.getInteger("count")).isGreaterThan(0);
        assertThat(result.getDouble("averageAge")).isNotNull();
    }
    
    private void createTestData() {
        mongoTemplate.insertAll(Arrays.asList(
            createUser("user1", 25, "ACTIVE"),
            createUser("user2", 30, "ACTIVE"),
            createUser("user3", 35, "ACTIVE"),
            createUser("user4", 40, "INACTIVE"),
            createUser("user5", 45, "INACTIVE")
        ));
    }
    
    private User createUser(String username, Integer age, String status) {
        User user = new User();
        user.setUsername(username);
        user.setEmail(username + "@example.com");
        user.setAge(age);
        user.setStatus(status);
        user.setCreatedAt(LocalDateTime.now());
        return user;
    }
}
```

```java
@SpringBootTest
@Testcontainers
@ActiveProfiles("integration-test")
class OrderServiceIntegrationTest extends AbstractMongoIntegrationTest {
    
    @Autowired
    private OrderService orderService;
    
    @Autowired
    private OrderRepository orderRepository;
    
    @Autowired
    private InventoryRepository inventoryRepository;
    
    @Autowired
    private MongoTemplate mongoTemplate;
    
    @BeforeEach
    void setUp() {
        mongoTemplate.dropCollection(Order.class);
        mongoTemplate.dropCollection(Inventory.class);
    }
    
    @Test
    @DisplayName("Should create order and update inventory")
    void testCreateOrder() {
        // Given
        String productId = "PROD-001";
        setupInventory(productId, 100);
        
        OrderRequest request = new OrderRequest();
        request.setUserId("USER-001");
        request.setItems(Arrays.asList(
            new OrderItem(productId, "Product 1", 5, new BigDecimal("29.99"))
        ));
        
        // When
        Order order = orderService.createOrder(request);
        
        // Then
        assertThat(order).isNotNull();
        assertThat(order.getId()).isNotNull();
        assertThat(order.getStatus()).isEqualTo("CONFIRMED");
        
        // Verify inventory updated
        Optional<Inventory> inventory = inventoryRepository.findByProductId(productId);
        assertThat(inventory).isPresent();
        assertThat(inventory.get().getQuantity()).isEqualTo(95);
    }
    
    @Test
    @DisplayName("Should fail when insufficient inventory")
    void testCreateOrderInsufficientInventory() {
        // Given
        String productId = "PROD-002";
        setupInventory(productId, 2);
        
        OrderRequest request = new OrderRequest();
        request.setUserId("USER-001");
        request.setItems(Arrays.asList(
            new OrderItem(productId, "Product 2", 5, new BigDecimal("29.99"))
        ));
        
        // When/Then
        assertThatThrownBy(() -> orderService.createOrder(request))
            .isInstanceOf(InsufficientInventoryException.class)
            .hasMessageContaining("Insufficient inventory");
        
        // Verify no order created
        List<Order> orders = orderRepository.findAll();
        assertThat(orders).isEmpty();
        
        // Verify inventory unchanged
        Optional<Inventory> inventory = inventoryRepository.findByProductId(productId);
        assertThat(inventory).isPresent();
        assertThat(inventory.get().getQuantity()).isEqualTo(2);
    }
    
    @Test
    @DisplayName("Should cancel order and restore inventory")
    void testCancelOrder() {
        // Given
        String productId = "PROD-003";
        setupInventory(productId, 100);
        
        OrderRequest request = new OrderRequest();
        request.setUserId("USER-001");
        request.setItems(Arrays.asList(
            new OrderItem(productId, "Product 3", 5, new BigDecimal("29.99"))
        ));
        
        Order order = orderService.createOrder(request);
        
        // When
        orderService.cancelOrder(order.getId());
        
        // Then
        Optional<Order> cancelledOrder = orderRepository.findById(order.getId());
        assertThat(cancelledOrder).isPresent();
        assertThat(cancelledOrder.get().getStatus()).isEqualTo("CANCELLED");
        
        // Verify inventory restored
        Optional<Inventory> inventory = inventoryRepository.findByProductId(productId);
        assertThat(inventory).isPresent();
        assertThat(inventory.get().getQuantity()).isEqualTo(100);
    }
    
    private void setupInventory(String productId, int quantity) {
        Inventory inventory = new Inventory();
        inventory.setProductId(productId);
        inventory.setQuantity(quantity);
        inventory.setReserved(0);
        inventoryRepository.save(inventory);
    }
}
```

### Testing Transactions with Testcontainers

**Transaction Tests:**

```java
@SpringBootTest
@Testcontainers
@ActiveProfiles("integration-test")
class TransactionIntegrationTest {
    
    @Container
    static MongoDBContainer mongoDBContainer = new MongoDBContainer("mongo:7.0")
        .withCommand("--replSet", "rs0");  // Enable replica set for transactions
    
    @DynamicPropertySource
    static void setProperties(DynamicPropertyRegistry registry) {
        registry.add("spring.data.mongodb.uri", () -> 
            mongoDBContainer.getReplicaSetUrl() + "?retryWrites=true");
    }
    
    @Autowired
    private BankingService bankingService;
    
    @Autowired
    private AccountRepository accountRepository;
    
    @Autowired
    private TransactionRepository transactionRepository;
    
    @BeforeAll
    static void initializeReplicaSet() throws Exception {
        // Initialize replica set
        mongoDBContainer.execInContainer(
            "mongosh",
            "--eval",
            "rs.initiate()"
        );
        
        // Wait for replica set to be ready
        Thread.sleep(5000);
    }
    
    @BeforeEach
    void setUp() {
        accountRepository.deleteAll();
        transactionRepository.deleteAll();
    }
    
    @Test
    @DisplayName("Should transfer money between accounts atomically")
    void testTransferMoney() {
        // Given
        Account fromAccount = createAccount("ACC-001", new BigDecimal("1000.00"));
        Account toAccount = createAccount("ACC-002", new BigDecimal("500.00"));
        
        // When
        Transaction transaction = bankingService.transferMoney(
            fromAccount.getId(),
            toAccount.getId(),
            new BigDecimal("250.00")
        );
        
        // Then
        assertThat(transaction.getStatus()).isEqualTo("COMPLETED");
        
        // Verify balances updated
        Account fromUpdated = accountRepository.findById(fromAccount.getId()).orElseThrow();
        Account toUpdated = accountRepository.findById(toAccount.getId()).orElseThrow();
        
        assertThat(fromUpdated.getBalance()).isEqualByComparingTo(new BigDecimal("750.00"));
        assertThat(toUpdated.getBalance()).isEqualByComparingTo(new BigDecimal("750.00"));
    }
    
    @Test
    @DisplayName("Should rollback transaction on insufficient funds")
    void testTransferInsufficientFunds() {
        // Given
        Account fromAccount = createAccount("ACC-003", new BigDecimal("100.00"));
        Account toAccount = createAccount("ACC-004", new BigDecimal("500.00"));
        
        BigDecimal initialFromBalance = fromAccount.getBalance();
        BigDecimal initialToBalance = toAccount.getBalance();
        
        // When/Then
        assertThatThrownBy(() ->
            bankingService.transferMoney(
                fromAccount.getId(),
                toAccount.getId(),
                new BigDecimal("250.00")
            )
        ).isInstanceOf(InsufficientFundsException.class);
        
        // Verify balances unchanged (rollback)
        Account fromAfter = accountRepository.findById(fromAccount.getId()).orElseThrow();
        Account toAfter = accountRepository.findById(toAccount.getId()).orElseThrow();
        
        assertThat(fromAfter.getBalance()).isEqualByComparingTo(initialFromBalance);
        assertThat(toAfter.getBalance()).isEqualByComparingTo(initialToBalance);
    }
    
    private Account createAccount(String accountNumber, BigDecimal balance) {
        Account account = new Account();
        account.setAccountNumber(accountNumber);
        account.setOwnerName("Test User");
        account.setBalance(balance);
        return accountRepository.save(account);
    }
}
```

```java
        Query query = new Query(Criteria.where("username").is(username));
        return mongoTemplate.findOne(query, User.class);
    }
    
    private Query buildQuery(UserSearchCriteria criteria) {
        Query query = new Query();
        List<Criteria> criteriaList = new ArrayList<>();
        
        if (criteria.getStatus() != null) {
            criteriaList.add(Criteria.where("status").is(criteria.getStatus()));
        }
        
        if (criteria.getMinAge() != null) {
            criteriaList.add(Criteria.where("age").gte(criteria.getMinAge()));
        }
        
        if (criteria.getMaxAge() != null) {
            criteriaList.add(Criteria.where("age").lte(criteria.getMaxAge()));
        }
        
        if (!criteriaList.isEmpty()) {
            query.addCriteria(new Criteria().andOperator(
                criteriaList.toArray(new Criteria[0])
            ));
        }
        
        return query;
    }
}

    private Integer minAge;
    private Integer maxAge;
```

## Interview Questions

**Q1: What's the difference between @DataMongoTest and @SpringBootTest for testing?**

@DataMongoTest: (1) Loads only MongoDB components (MongoTemplate, repositories), (2) Fast startup, (3) Focused on repository layer, (4) Auto-configures embedded MongoDB. @SpringBootTest: (1) Loads full application context, (2) Slower startup, (3) Tests entire application, (4) Requires explicit database configuration. Use @DataMongoTest for repository tests, @SpringBootTest for integration tests.

**Q2: When should you use Testcontainers vs embedded MongoDB?**

Embedded MongoDB (Flapdoodle): Fast, no Docker required, good for repository tests, limited MongoDB features. Testcontainers: Production-like environment, real MongoDB, supports all features (transactions, replica sets), requires Docker. Use embedded for unit/repository tests, Testcontainers for integration tests requiring transactions or specific MongoDB versions.

**Q3: How do you test MongoDB transactions?**

Requires replica set (use Testcontainers with `--replSet` command). Test scenarios: (1) Successful transaction - verify commit, (2) Failed transaction - verify rollback, (3) Concurrent transactions - verify isolation. Use @Transactional or programmatic transactions. Verify data state before/after with assertions. Test with realistic error scenarios (insufficient funds, constraint violations).

**Q4: What are best practices for MongoDB test data management?**

Use test data builders for readable creation. Create test fixtures for reusable setup. Clean up between tests (@BeforeEach cleanup). Use separate test database. Don't share data between tests. Generate realistic data volumes. Use meaningful test data (not "test1", "test2"). Create helper methods for common data patterns. Consider using factory pattern for complex entities.

**Q5: How do you performance test MongoDB operations?**

Measure operations with realistic data volumes (10K+ documents). Test: (1) Bulk inserts - throughput (docs/sec), (2) Indexed queries - avg query time (<50ms), (3) Aggregations - completion time, (4) Concurrent operations - thread safety. Use explain() to verify index usage. Monitor: execution time, documents examined vs returned, stage (IXSCAN vs COLLSCAN). Set performance thresholds in assertions.

MongoDB testing requires layered approach:

- ✅ **Embedded MongoDB** - Fast unit/repository tests with Flapdoodle
